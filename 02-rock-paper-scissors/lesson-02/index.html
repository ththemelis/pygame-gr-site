    Μάθημα 2: Πέτρα, ψαλίδι, χαρτί¶

    Παιχνίδι: αγώνας εναντίον του υπολογιστή, μέχρι να φτάσει κάποιος τους πόντους νίκης
    Διάρκεια: 4 κύκλοι × (περίπου 45′ εργασία + 15′ διάλειμμα)

    Φύλλο εργασίας

    Αυτή η σελίδα εξηγεί τις έννοιες. Οι ασκήσεις και οι οδηγίες για κάθε κύκλο βρίσκονται στο Φύλλο εργασίας 2. Δούλεψε με τις δύο σελίδες ανοιχτές.

    Αρχεία εργαστηρίου¶

    01-one-round.py 1
    02-valid-round.py 2

    Η αποστολή¶

    Στο Μάθημα 1 ο υπολογιστής διάλεγε έναν αριθμό και εσύ τον μάντευες. Σήμερα παίζει απέναντί σου: διαλέγει τυχαία πέτρα, ψαλίδι ή χαρτί, και νικητής είναι όποιος φτάσει πρώτος τους πόντους που θα ορίσεις στην αρχή (από 1 έως 5).

    Για να γίνει αυτό, το πρόγραμμα χρειάζεται τρία πράγματα που δεν έχεις δει ακόμη:

    1. Έναν τρόπο να κρατά τις τρεις επιλογές μαζί. Αυτό είναι η λίστα.
    2. Έναν τρόπο να αντιδρά όταν ο παίκτης γράψει κάτι άκυρο, αντί να σταματά με σφάλμα. Αυτό είναι ο έλεγχος εισόδου και οι εξαιρέσεις.
    3. Έναν τρόπο να παίζει πολλούς γύρους, όπου κάθε γύρος ζητά με τη σειρά του είσοδο. Αυτό είναι οι φωλιασμένοι βρόχοι.

    Στο τέλος θα μπορείς¶

    • να δημιουργείς λίστα και να παίρνεις στοιχεία με δείκτη, ξεκινώντας από το 0.
    • να χρησιμοποιείς τη len() και τους τελεστές in και not in.
    • να επιλέγεις τυχαίο στοιχείο λίστας με random.choice().
    • να ζητάς είσοδο μέχρι να είναι έγκυρη, με while True και break.
    • να φωλιάζεις έναν βρόχο μέσα σε άλλον και να εξηγείς ποιον σταματά το break.
    • να δίνεις τιμή σε δύο μεταβλητές με μία πολλαπλή εκχώρηση.
    • να πιάνεις το σφάλμα ValueError με try/except και να συνεχίζεις με continue.
    • να ελέγχεις ότι ένας αριθμός είναι μέσα σε όρια με αλυσιδωτή σύγκριση.
    • να δοκιμάζεις την είσοδο ενός προγράμματος με έγκυρες, άκυρες και οριακές τιμές.
    • να χρησιμοποιείς τις ενσωματωμένες συναρτήσεις min, max, sum και abs.
    • να γράφεις μια απλή απόφαση σε μία γραμμή, με την έκφραση α if συνθήκη else β.

    Κύκλος 1 — Λίστες και ένας γύρος¶

    Σε αυτόν τον κύκλο μαθαίνεις να κρατάς πολλές τιμές σε μία μεταβλητή και χρησιμοποιείς τη λίστα για να παίξεις έναν γύρο.

    1.1 Γιατί χρειάζεται λίστα¶

    Οι τρεις επιλογές του παιχνιδιού είναι ένα σύνολο που ανήκει μαζί. Θα μπορούσες να γράψεις τρεις μεταβλητές (choice1, choice2, choice3), αλλά τότε κάθε φορά που θέλεις να διαλέξεις μία από αυτές χρειάζεσαι ξεχωριστό if, και αν προσθέσεις μία τέταρτη επιλογή αλλάζεις όλο το πρόγραμμα.

    Η λίστα (list) είναι μια μεταβλητή που κρατά πολλές τιμές, με σειρά. Γράφεται με αγκύλες και κόμματα:

    CHOICES = ["πέτρα", "ψαλίδι", "χαρτί"]
    • Οι τιμές της λίστας λέγονται στοιχεία (elements).
    • Μια λίστα μπορεί να κρατά οποιουσδήποτε τύπους, ακόμη και μπερδεμένους: [7, "Αλέξης", True, 3.5].
    • Μια λίστα χωρίς στοιχεία είναι η κενή λίστα: [].
    • Το όνομα γράφεται με κεφαλαία (CHOICES), επειδή οι επιλογές δεν αλλάζουν όσο τρέχει το παιχνίδι. Είναι η σύμβαση για σταθερές που είδες στο Μάθημα 1.

    1.2 Δείκτες: ποιο στοιχείο θέλω;¶

    Κάθε στοιχείο έχει μια θέση, που λέγεται δείκτης (index). Η αρίθμηση ξεκινά από το 0, όχι από το 1:

    Δείκτης 0 1 2
    Στοιχείο "πέτρα" "ψαλίδι" "χαρτί"

    Παίρνεις ένα στοιχείο γράφοντας το όνομα της λίστας και τον δείκτη μέσα σε αγκύλες:

    CHOICES = ["πέτρα", "ψαλίδι", "χαρτί"]
print(CHOICES[0])    # πέτρα
print(CHOICES[2])    # χαρτί

    Το 0 μοιάζει περίεργο, αλλά αυτός είναι ο κανόνας στην Python, στη C και στις περισσότερες γλώσσες. Ο δείκτης δείχνει «πόσες θέσεις μετά την αρχή».

    Η Python δέχεται και αρνητικούς δείκτες, που μετρούν από το τέλος: το CHOICES[-1] είναι το τελευταίο στοιχείο και το CHOICES[-3] το τρίτο από το τέλος. Θα το δεις να έχει σημασία σε λίγο.

    Αν ζητήσεις δείκτη που δεν υπάρχει, παίρνεις σφάλμα:

    IndexError: list index out of range

    Το CHOICES[3] είναι σφάλμα, γιατί η λίστα έχει στοιχεία μόνο στις θέσεις 0, 1 και 2.

    1.3 Μήκος της λίστας: len¶

    Η len() δίνει το πλήθος των στοιχείων:

    print(len(CHOICES))   # 3

    Ο τελευταίος δείκτης είναι πάντα len(CHOICES) - 1. Μια λίστα με 3 στοιχεία έχει δείκτες 0, 1, 2. Αυτό το «κατά ένα» είναι η πιο συνηθισμένη πηγή λαθών με λίστες.

    Η len είναι μια ενσωματωμένη συνάρτηση (built-in function): μια έτοιμη συνάρτηση που υπάρχει πάντα στην Python, χωρίς import. Ξέρεις ήδη την print, την input και την int. Τέσσερις ακόμη δουλεύουν σε αριθμούς και σε λίστες αριθμών:

    scores = [12, 7, 30, 18]
print(min(scores))                  # 7
print(max(scores))                  # 30
print(sum(scores))                  # 67
print(sum(scores) / len(scores))    # 16.75
    Συνάρτηση Τι δίνει Παράδειγμα
    len(λίστα) το πλήθος των στοιχείων len([4, 8, 1]) → 3
    min(λίστα) το μικρότερο στοιχείο min([4, 8, 1]) → 1
    max(λίστα) το μεγαλύτερο στοιχείο max([4, 8, 1]) → 8
    sum(λίστα) το άθροισμα των στοιχείων sum([4, 8, 1]) → 13
    abs(αριθμός) η απόλυτη τιμή: ο αριθμός χωρίς πρόσημο abs(-5) → 5
    • Οι min και max δέχονται και δύο ή περισσότερους αριθμούς χωρίς λίστα: το min(3, 9) δίνει 3 και το max(3, 9, 5) δίνει 9.
    • Μια κενή λίστα δεν έχει μικρότερο ή μεγαλύτερο στοιχείο: η min([]) και η max([]) δίνουν ValueError: min() iterable argument is empty (και αντίστοιχα για τη max). Η sum([]) δίνει 0.

    1.4 Ανήκει η τιμή στη λίστα: in και not in¶

    Οι τελεστές in και not in ελέγχουν αν μια τιμή υπάρχει σε μια λίστα και απαντούν με True ή False:

    print("ψαλίδι" in CHOICES)       # True
print("σαύρα" in CHOICES)        # False
print("σαύρα" not in CHOICES)    # True

    Θα τους χρησιμοποιήσεις στον έλεγχο της εισόδου, στον επόμενο κύκλο.

    1.5 Αλλαγή στοιχείου¶

    Μπορείς να αντικαταστήσεις ένα στοιχείο, δίνοντάς του νέα τιμή με τον δείκτη του:

    numbers = [1, 2, 3]
numbers[0] = 9
print(numbers)    # [9, 2, 3]

    Λέμε ότι οι λίστες είναι τροποποιήσιμες (mutable): αλλάζουν στη θέση τους. Στο Μάθημα 3 θα μάθεις και να προσθέτεις στοιχεία.

    1.6 Από τον αριθμό του μενού στον δείκτη¶

    Ο παίκτης βλέπει το μενού «1 = πέτρα, 2 = ψαλίδι, 3 = χαρτί» και γράφει έναν αριθμό από το 1 έως το 3. Η λίστα όμως έχει δείκτες από το 0 έως το 2. Χρειάζεται μια μετατροπή: ο δείκτης είναι ο αριθμός μείον 1.

    Ο παίκτης γράφει 1 2 3
    Δείκτης = αριθμός − 1 0 1 2
    Επιλογή πέτρα ψαλίδι χαρτί 
    number = int(input("Η επιλογή σου: "))
player = CHOICES[number - 1]

    Τι γίνεται αν ο παίκτης γράψει 0 ή 4;

    Με 4, ο δείκτης είναι 3 και έχεις IndexError. Με 0, ο δείκτης είναι -1, και το CHOICES[-1] είναι έγκυρο: δίνει «χαρτί». Το πρόγραμμα δεν σταματά, αλλά κάνει κάτι που ο παίκτης δεν ζήτησε. Αυτό είναι χειρότερο από ένα σφάλμα, γιατί δεν φαίνεται. Γι' αυτό ο επόμενος κύκλος αφιερώνεται στον έλεγχο της εισόδου.

    1.7 Οι κανόνες του παιχνιδιού ως συνθήκες¶

    Η πέτρα νικά το ψαλίδι, το ψαλίδι νικά το χαρτί, το χαρτί νικά την πέτρα. Αν οι επιλογές είναι ίδιες, έχουμε ισοπαλία. Ο υπολογιστής δεν «ξέρει» τους κανόνες· τους γράφουμε εμείς ως συνθήκες.

    Παίκτης \ Υπολογιστής πέτρα ψαλίδι χαρτί
    πέτρα ισοπαλία νικά ο παίκτης χάνει ο παίκτης
    ψαλίδι χάνει ο παίκτης ισοπαλία νικά ο παίκτης
    χαρτί νικά ο παίκτης χάνει ο παίκτης ισοπαλία

    Η λογική είναι τρεις περιπτώσεις με σειρά:

    1. Αν οι επιλογές είναι ίδιες: ισοπαλία.
    2. Αλλιώς, αν ισχύει ένα από τα τρία ζευγάρια νίκης του παίκτη: νικά ο παίκτης.
    3. Σε κάθε άλλη περίπτωση: νικά ο υπολογιστής.
    if player == computer:
    print("Ισοπαλία.")
elif (
    (player == "πέτρα" and computer == "ψαλίδι")
    or (player == "ψαλίδι" and computer == "χαρτί")
    or (player == "χαρτί" and computer == "πέτρα")
):
    print("Κέρδισες τον γύρο.")
else:
    print("Κέρδισε ο υπολογιστής τον γύρο.")

    Τρεις παρατηρήσεις:

    • Κάθε ζευγάρι νίκης είναι ένα and (και οι δύο επιλογές ισχύουν ταυτόχρονα). Τα τρία ζευγάρια συνδέονται με or (αρκεί να ισχύει ένα). Είναι ο συνδυασμός and/or του Μαθήματος 1.
    • Μέσα σε παρενθέσεις, μια εντολή μπορεί να συνεχίζεται σε πολλές γραμμές. Έτσι η συνθήκη διαβάζεται εύκολα. Η εσοχή μέσα στις παρενθέσεις είναι προαιρετική, αλλά βοηθά.
    • Το else δεν χρειάζεται συνθήκη. Όταν δεν είναι ισοπαλία και δεν νικά ο παίκτης, νικά αναγκαστικά ο υπολογιστής. Αυτό ισχύει μόνο αν οι επιλογές είναι έγκυρες· γι' αυτό ο έλεγχος της εισόδου είναι απαραίτητος.

    Στάδιο 1 — Ένας γύρος¶

    Άνοιξε το 01-one-round.py. Ο υπολογιστής παίζει προς το παρόν πάντα το δεύτερο στοιχείο της λίστας, το ψαλίδι. Συμπλήρωσε τα τρία κενά και παίξε με τα 1, 2, 3.

    """Στάδιο 1 — Ένας γύρος με σταθερή επιλογή υπολογιστή.

Ο παίκτης διαλέγει 1, 2 ή 3. Ο υπολογιστής παίζει προς το παρόν πάντα το ίδιο
(το δεύτερο στοιχείο της λίστας). Το πρόγραμμα λέει ποιος κέρδισε.

"""

CHOICES = ["πέτρα", "ψαλίδι", "χαρτί"]

print(f"1 = {CHOICES[0]}, 2 = {CHOICES[1]}, 3 = {CHOICES[____]}")
number = int(input("Η επιλογή σου: "))

# TODO 2: το μενού αρχίζει από το 1, οι δείκτες από το 0. Μετάτρεψε τον αριθμό σε δείκτη.
player = CHOICES[number ____ 1]
computer = CHOICES[1]
print(f"Εσύ: {player} | Υπολογιστής: {computer}")

if player == computer:
    print("Ισοπαλία.")
elif (
    (player == "πέτρα" and computer == "ψαλίδι")
    or (player == "ψαλίδι" and computer == "χαρτί")
    # TODO 3: το χαρτί κερδίζει ποιον;
    or (player == "χαρτί" and computer == ____)
):
    print("Κέρδισες τον γύρο.")
else:
    print("Κέρδισε ο υπολογιστής τον γύρο.")

    Κύκλος 2 — Τυχαία επιλογή και έγκυρη είσοδος¶

    Σε αυτόν τον κύκλο ο υπολογιστής αρχίζει να παίζει τυχαία, και το πρόγραμμα μαθαίνει να ζητά είσοδο ξανά και ξανά, μέχρι να είναι έγκυρη.

    2.1 Τυχαίο στοιχείο: random.choice¶

    Στο Μάθημα 1 η random.randint(a, b) έδινε τυχαίο ακέραιο. Για μια λίστα υπάρχει πιο άμεσος τρόπος: η random.choice() διαλέγει ένα τυχαίο στοιχείο της λίστας:

    import random

CHOICES = ["πέτρα", "ψαλίδι", "χαρτί"]
computer = random.choice(CHOICES)

    Κάθε στοιχείο έχει την ίδια πιθανότητα (ένα στα τρία). Θα μπορούσες να πετύχεις το ίδιο με δείκτη, γράφοντας CHOICES[random.randint(0, len(CHOICES) - 1)]. Δες πόσα πράγματα από αυτό το μάθημα συνδυάζονται εκεί: δείκτης, len, - 1, randint. Η random.choice κάνει όλη αυτή τη δουλειά με μία κλήση.

    2.2 Βρόχος που τον σταματάς εσύ: while True και break¶

    Μέχρι τώρα ο βρόχος while είχε μια συνθήκη που τον τελείωνε. Μερικές φορές δεν ξέρεις από πριν πότε θα τελειώσει: συνεχίζεις μέχρι να συμβεί κάτι μέσα στον βρόχο. Τότε γράφεις:

    while True:
    # ... εντολές ...
    if κάτι_συνέβη:
        break

    3.1 Πολλαπλή εκχώρηση¶

    Δύο μεταβλητές που ξεκινούν από την ίδια τιμή μπορούν να οριστούν μαζί:

    player_score, computer_score = 0, 0

    Η Python υπολογίζει πρώτα τη δεξιά πλευρά (το ζευγάρι 0, 0) και μετά δίνει στην πρώτη μεταβλητή την πρώτη τιμή και στη δεύτερη τη δεύτερη. Είναι ισοδύναμο με δύο ξεχωριστές γραμμές, αλλά πιο σύντομο.

    Η ίδια ιδέα λύνει ένα κλασικό πρόβλημα: την ανταλλαγή δύο τιμών. Σε άλλες γλώσσες χρειάζεσαι τρίτη μεταβλητή. Στην Python:

    a, b = 1, 2
a, b = b, a
print(a, b)    # 2 1

    Η δεξιά πλευρά υπολογίζεται πριν γίνει οποιαδήποτε εκχώρηση, γι' αυτό δεν χάνεται καμία τιμή.

    3.2 Φωλιασμένοι βρόχοι¶

    Ένας βρόχος μπορεί να βρίσκεται μέσα σε άλλον βρόχο. Στο παιχνίδι έχουμε:

    • τον εξωτερικό βρόχο, που παίζει τους γύρους του αγώνα,
    • τον εσωτερικό βρόχο (while True), που σε κάθε γύρο ζητά την επιλογή μέχρι να είναι έγκυρη.
    while player_score < WIN_SCORE and computer_score < WIN_SCORE:   # εξωτερικός: γύροι
    ...
    while True:                                                  # εσωτερικός: έγκυρη επιλογή
        answer = input("Η επιλογή σου: ").strip()
        if answer in ["1", "2", "3"]:

        print("Η επιλογή πρέπει να είναι 1, 2 ή 3.")
    ...

    Ο κανόνας που πρέπει να θυμάσαι: για κάθε επανάληψη του εξωτερικού βρόχου, ο εσωτερικός εκτελείται ολόκληρος, από την αρχή.

    Το break σταματά μόνο τον πιο εσωτερικό βρόχο

    Το break μέσα στον εσωτερικό βρόχο τελειώνει αυτόν, και ο εξωτερικός συνεχίζει. Δεν τελειώνει ο αγώνας. Αυτό θέλουμε εδώ: μετά τον έλεγχο της επιλογής, ο γύρος συνεχίζει.

    Ιχνηλάτηση ενός μικρού παραδείγματος:

    round_number = 1

    while True:

        if tries == 3:

    εξωτερικός, γύρος 1 1 1, 2, 3 → break 1 3
    εξωτερικός, γύρος 2 2 ξαναρχίζει από 0: 1, 2, 3 → break 2 3
    έλεγχος 3 <= 2 3 — ο εξωτερικός τελειώνει

    3.3 Πότε τελειώνει ο αγώνας¶

    3.4 Ισοπαλίες, σκορ και αριθμός γύρου¶

    • Σε ισοπαλία κανείς δεν παίρνει πόντο, αλλά ο γύρος μετρά (ο αριθμός γύρου αυξάνεται).
    • Ο πόντος προστίθεται μέσα στον κλάδο που αποφασίζει τον νικητή, και όχι μετά από όλους τους κλάδους.
    • Το σκορ εμφανίζεται μετά την απόφαση, ώστε να δείχνει την ενημερωμένη τιμή.
    • Η αύξηση του αριθμού γύρου (round_number += 1) είναι το τελευταίο βήμα του σώματος. Αν ξεχαστεί, ο γύρος εμφανίζεται συνέχεια με τον ίδιο αριθμό.

    Κύκλος 4 — Ανθεκτική είσοδος¶

    Ο έλεγχος με in δουλεύει όταν οι επιτρεπτές τιμές είναι λίγες και γνωστές: "1", "2", "3". Αν όμως δεχόμαστε οποιονδήποτε αριθμό σε ένα εύρος, δεν μπορούμε να γράψουμε όλες τις τιμές. Εδώ χρειάζονται οι εξαιρέσεις.

    4.1 Εξαιρέσεις: try και except¶

    Στο Μάθημα 1 είδες ότι το int("abc") σταματά το πρόγραμμα:

    ValueError: invalid literal for int() with base 10: 'abc'

    Το σφάλμα εκτέλεσης που σταματά ένα πρόγραμμα λέγεται εξαίρεση (exception). Η ValueError είναι ο τύπος της εξαίρεσης. Μπορούμε να πιάσουμε μια εξαίρεση και να αποφασίσουμε εμείς τι θα γίνει:

    try:
    win_score = int(answer)
except ValueError:
    print("Γράψε έναν ακέραιο αριθμό.")

    Πώς εκτελείται:

    1. Η Python εκτελεί το μπλοκ του try.
    2. Αν δεν προκύψει εξαίρεση, το μπλοκ του except παραλείπεται και το πρόγραμμα συνεχίζει.
    3. Αν προκύψει εξαίρεση τύπου ValueError, η εκτέλεση του try σταματά αμέσως (οι εντολές που απομένουν στο μπλοκ δεν εκτελούνται) και πηγαίνει στο μπλοκ του except ValueError. Μετά, το πρόγραμμα συνεχίζει κανονικά κάτω από το try/except.
    Είσοδος Τι γίνεται στο try Μπλοκ except; win_score μετά
    "5" η int("5") δίνει 5, η εκχώρηση ολοκληρώνεται δεν εκτελείται 5
    "abc" η int("abc") προκαλεί ValueError, η εκχώρηση δεν γίνεται εκτελείται δεν έχει οριστεί

    Δύο κανόνες:

    • Όρισε τον τύπο της εξαίρεσης (except ValueError). Αν γράψεις except: χωρίς τύπο, πιάνεις κάθε σφάλμα, ακόμα και τα λάθη του κώδικά σου, και τα κρύβεις. Πιάνουμε μόνο ό,τι περιμένουμε.
    • Βάζε στο try μόνο τις εντολές που μπορεί να αποτύχουν. Όσο μικρότερο το μπλοκ, τόσο πιο σαφές τι πιάνεις.

    4.2 Η εντολή continue¶

    Το break βγαίνει από τον βρόχο. Το continue κάνει κάτι διαφορετικό: παραλείπει τις υπόλοιπες εντολές του τρέχοντος γύρου και πηγαίνει στον επόμενο γύρο του ίδιου βρόχου.

    Εντολή Τι κάνει
    break τελειώνει τον βρόχο· η εκτέλεση συνεχίζει μετά τον βρόχο
    continue τελειώνει αυτόν τον γύρο· η εκτέλεση πηγαίνει στην αρχή του βρόχου (και ελέγχεται ξανά η συνθήκη)

    Στον έλεγχο εισόδου, αν η μετατροπή αποτύχει θέλουμε να ρωτήσουμε ξανά, χωρίς να φτάσουμε στη γραμμή που χρησιμοποιεί το win_score (που δεν έχει οριστεί). Το continue κάνει ακριβώς αυτό.

    4.3 Αλυσιδωτή σύγκριση¶

    Για να ελέγξεις ότι ένας αριθμός είναι ανάμεσα σε δύο όρια, η Python σου επιτρέπει να γράψεις τη σύγκριση όπως στα μαθηματικά:

    if 1 <= win_score <= 5:

    Είναι ισοδύναμο με win_score >= 1 and win_score <= 5, αλλά διαβάζεται πιο φυσικά και γράφεται μία φορά η μεταβλητή. Τα όρια περιλαμβάνονται λόγω των <=.

    Αν έχεις γράψει C

    Στη C, το 1 <= n <= 5 δεν κάνει αυτό. Υπολογίζεται ως (1 <= n) <= 5: η πρώτη σύγκριση δίνει 0 ή 1, και το 0 ή 1 είναι πάντα <= 5, άρα η συνθήκη είναι πάντα αληθής. Στη C γράφεις n >= 1 && n <= 5. Η αλυσιδωτή σύγκριση είναι χαρακτηριστικό της Python.

    4.4 Το πρότυπο «ζήτα μέχρι να είναι έγκυρο» για αριθμούς¶

    Συνδυάζοντας όλα τα παραπάνω:

    while True:
    answer = input("Πόντοι για τη νίκη (1-5): ")
    try:
        win_score = int(answer)
    except ValueError:
        print("Γράψε έναν ακέραιο αριθμό.")
        continue
    if 1 <= win_score <= 5:
        break
    print("Ο αριθμός πρέπει να είναι από 1 έως 5.")

    Δύο ξεχωριστοί έλεγχοι, με σειρά:

    1. Είναι αριθμός; Το αποφασίζει το try/except. Αν όχι, μήνυμα και continue.
    2. Είναι μέσα στα όρια; Το αποφασίζει η αλυσιδωτή σύγκριση. Αν ναι, break. Αν όχι, εμφανίζεται το μήνυμα και ο βρόχος συνεχίζει φυσιολογικά.

    Δεν μπορείς να αντιστρέψεις τη σειρά: ο έλεγχος ορίων χρειάζεται αριθμό, και ο αριθμός υπάρχει μόνο αν πέτυχε η μετατροπή.

    Ιχνηλάτηση:

    Είσοδος Μετατροπή Όρια Αποτέλεσμα
    "abc" αποτυγχάνει → μήνυμα → continue δεν ελέγχονται ρωτά ξανά
    "9" 9 1 <= 9 <= 5 → False → μήνυμα ρωτά ξανά
    "3" 3 1 <= 3 <= 5 → True → break δεκτό

    Αυτό το πρότυπο θα το ξαναχρησιμοποιήσεις σε κάθε πρόγραμμα που ζητά αριθμό από τον χρήστη.

    4.6 Το if σε μία γραμμή¶

    Η Python έχει δύο συντομογραφίες για απλές αποφάσεις. Δεν κάνουν κάτι που δεν μπορείς να κάνεις με το γνωστό if/else· κάνουν τον κώδικα πιο σύντομο όταν η απόφαση είναι μικρή.

    Α. Μία εντολή στην ίδια γραμμή. Αν το μπλοκ ενός if έχει μία μόνο εντολή, μπορείς να τη γράψεις μετά την άνω και κάτω τελεία, χωρίς αλλαγή γραμμής:

    score = 3
if score >= 3: print("Κέρδισες τον αγώνα.")

    Κέρδισες τον αγώνα.

    Κάνει ακριβώς ό,τι κάνει η συνήθης γραφή με εσοχή:

    score = 3
if score >= 3:
    print("Κέρδισες τον αγώνα.")

    Το elif και το else: γράφονται σε δική τους γραμμή και μπορούν κι αυτά να έχουν μία εντολή στην ίδια γραμμή. Δεν μπορείς όμως να βάλεις το if, το else: και τις δύο εντολές όλα σε μία γραμμή: αυτό είναι SyntaxError. Γι' αυτό υπάρχει η δεύτερη συντομογραφία, παρακάτω. Χρησιμοποίησε την πρώτη με φειδώ: όταν το μπλοκ μεγαλώσει, πρέπει να ξαναγραφτεί με εσοχή.

    Β. Η έκφραση α if συνθήκη else β. Εδώ το if δεν είναι εντολή αλλά έκφραση: δίνει μια τιμή, όπως οι αριθμητικές πράξεις. Δίνει το α αν η συνθήκη ισχύει, αλλιώς το β.

    win_score = 1
points = "πόντο" if win_score == 1 else "πόντους"
print(f"Παίζουμε μέχρι {win_score} {points}.")

    Παίζουμε μέχρι 1 πόντο.

    Η γραμμή points = ... ισοδυναμεί με αυτό το if/else των τεσσάρων γραμμών:

    if win_score == 1:
    points = "πόντο"
else:
    points = "πόντους"

    Η έκφραση μπορεί να μπει παντού όπου μπαίνει μια τιμή, π.χ. μέσα σε μια print:

    n = 7
print("άρτιος" if n % 2 == 0 else "περιττός")    # περιττός

    Δύο κανόνες:

    • Το else είναι υποχρεωτικό στην έκφραση, γιατί η έκφραση πρέπει να δίνει πάντα τιμή. Το label = "ναι" if n > 3 δίνει SyntaxError: expected 'else' after 'if' expression.
    • Μπορείς να βάλεις μια δεύτερη έκφραση στη θέση του β, για τρεις περιπτώσεις. Διαβάζεται από αριστερά προς τα δεξιά:
    score = 72
grade = "Άριστα" if score >= 90 else "Καλά" if score >= 50 else "Μελέτη"
print(grade)

    Καλά

    Με δύο συνθήκες ή περισσότερες η μία γραμμή γίνεται δυσανάγνωστη. Τότε γράψε ολόκληρο το if/elif/else.

    εκτελέσεις πολλές εντολές, ή να ξεχωρίσεις πολλές περιπτώσεις if/elif/else με εσοχή
    διαλέξεις μία τιμή ανάμεσα σε δύο α if συνθήκη else β
    εκτελέσεις μία σύντομη εντολή όταν ισχύει κάτι if συνθήκη: εντολή (με φειδώ)

    Για να θυμάσαι¶

    • Μια λίστα κρατά πολλά στοιχεία με σειρά. Ο πρώτος δείκτης είναι το 0 και ο τελευταίος το len(λίστα) - 1. Ο αρνητικός δείκτης μετρά από το τέλος.
    • Το in ελέγχει αν μια τιμή ανήκει σε λίστα. Η random.choice διαλέγει τυχαίο στοιχείο.
    • Το while True με break ζητά είσοδο μέχρι να είναι έγκυρη. Το break σταματά τον πιο εσωτερικό βρόχο.
    • Ο εσωτερικός βρόχος εκτελείται ολόκληρος σε κάθε επανάληψη του εξωτερικού.
    • Η πολλαπλή εκχώρηση a, b = 0, 0 δίνει τιμή σε δύο μεταβλητές. Η a, b = b, a τις ανταλλάσσει.
    • Το try/except ValueError πιάνει το σφάλμα της int() και επιτρέπει στο πρόγραμμα να συνεχίσει. Πιάνουμε μόνο τον τύπο εξαίρεσης που περιμένουμε.
    • Το continue πηγαίνει στον επόμενο γύρο του βρόχου. Το break βγαίνει από τον βρόχο.
    • Η αλυσιδωτή σύγκριση 1 <= n <= 5 ελέγχει εύρος. Έλεγξε την είσοδο με έγκυρες, άκυρες και οριακές τιμές.
    • Οι len, min, max, sum και abs είναι έτοιμες ενσωματωμένες συναρτήσεις. Η min και η max δίνουν ValueError σε κενή λίστα.
    • Το α if συνθήκη else β είναι έκφραση που δίνει τιμή και θέλει πάντα else. Για πολλές περιπτώσεις γράφεις if/elif/else.
