    Φυλλάδιο εξάσκησης — συναρτήσεις, λίστες, λεξικά, πλειάδες¶

    Για ποιον: όποιον θέλει περισσότερη εξάσκηση στα Μαθήματα 2–4
    Διάρκεια: 5 μέρη, περίπου 45′ το καθένα. Κάθε μέρος στέκεται μόνο του.

    Πώς δουλεύουμε

    Η θεωρία είναι στα μαθήματα: Μάθημα 2 (λίστες), Μάθημα 3 (μέθοδοι λιστών) και Μάθημα 4 (συναρτήσεις, λεξικά, πλειάδες). Εδώ είναι μόνο ασκήσεις, με μια σύντομη υπενθύμιση στην αρχή κάθε μέρους.

    Στις ασκήσεις πρόβλεψης, ιχνηλάτησης, «σωστό ή λάθος» και «βρες το σφάλμα» γράψε πρώτα την απάντησή σου και μετά τρέξε τον κώδικα στο sandbox.py. Μπορείς να εκτυπώσεις τη σελίδα ή να γράφεις τις απαντήσεις στο τετράδιό σου.

    Οι ασκήσεις «Γράψε εσύ» γράφονται στο αρχείο practice.py. Μετά από κάθε μία, τρέξε τον αυτοέλεγχο του μέρους (π.χ. python check_practice.py lists) και διάβασε το αποτέλεσμα. Οι ασκήσεις με τίτλο «Πρόκληση» είναι για όποιον τελειώνει νωρίτερα.

    Υπενθύμιση¶

    Μάθημα 4, ενότητες 1.1–1.9 και 4.1–4.2.

    • Το def όνομα(παράμετροι): ορίζει μια συνάρτηση. Η κλήση όνομα(ορίσματα) την εκτελεί.
    • Η return τιμή επιστρέφει την τιμή σε αυτόν που κάλεσε τη συνάρτηση και την τελειώνει αμέσως. Η print μόνο εμφανίζει κάτι στην οθόνη. Μια συνάρτηση που δεν φτάνει σε return επιστρέφει None.
    • Οι μεταβλητές που δημιουργείς μέσα σε μια συνάρτηση, και οι παράμετροί της, υπάρχουν μόνο εκεί.
    • Μια παράμετρος με προεπιλογή (def f(a, b=5):) μπορεί να παραλειφθεί στην κλήση. Μπορείς να δώσεις ορίσματα και με όνομα: f(1, b=7).

    Α3. Σωστό ή λάθος; (3′)¶

    Πρόταση
    1 Μια συνάρτηση χωρίς return επιστρέφει None. Σ / Λ
    2 Μετά το return, η συνάρτηση συνεχίζει με τις επόμενες γραμμές της. Σ / Λ
    3 Μια μεταβλητή που δημιουργείται μέσα σε μια συνάρτηση φαίνεται και έξω από αυτήν. Σ / Λ
    4 Αν ο ορισμός είναι def f(a, b=5):, η κλήση f(1) είναι έγκυρη. Σ / Λ
    5 Αν ο ορισμός είναι def f(a, b):, η κλήση f(1) είναι έγκυρη. Σ / Λ
    6 Αν η f έχει return, η γραμμή f(3) μόνη της εμφανίζει το αποτέλεσμα στην οθόνη. Σ / Λ

    Α6. Γράψε εσύ: is_even (3′)¶

    Γράψε στο practice.py το σώμα της is_even(number). Επιστρέφει True αν ο ακέραιος είναι άρτιος και False αν είναι περιττός.

    Παραδείγματα: is_even(4) επιστρέφει True, is_even(7) επιστρέφει False, is_even(-3) επιστρέφει False.

    Α7. Γράψε εσύ: clamp (4′)¶

    Γράψε το σώμα της clamp(value, low, high). Επιστρέφει την τιμή value, αλλά όχι μικρότερη από το low και όχι μεγαλύτερη από το high.

    Παραδείγματα: clamp(15, 0, 10) επιστρέφει 10, clamp(-3, 0, 10) επιστρέφει 0, clamp(5, 0, 10) επιστρέφει 5.

    Υποδείξεις: γράψε την πρώτα με δύο if (ένα για κάθε όριο) και μετά ξαναγράψε τη συνάρτηση σε μία γραμμή με το πρότυπο max(low, min(value, high)). Τρέξε τον αυτοέλεγχο και για τις δύο εκδοχές.

    Α8. Γράψε εσύ: grade_text (4′)¶

    Γράψε το σώμα της grade_text(score). Επιστρέφει κείμενο για έναν βαθμό από 0 έως 100: από 90 "άριστα", από 70 "πολύ καλά", από 50 "καλά", αλλιώς "χρειάζεσαι εξάσκηση".

    Παραδείγματα: grade_text(95) επιστρέφει "άριστα", grade_text(70) επιστρέφει "πολύ καλά", grade_text(69) επιστρέφει "καλά", grade_text(49) επιστρέφει "χρειάζεσαι εξάσκηση".

    Υποδείξεις: ξεκίνα από το μεγαλύτερο όριο. Κάθε if έχει return, άρα οι επόμενοι έλεγχοι δεν εκτελούνται όταν ισχύει ένας προηγούμενος. Προσοχή στα όρια: το «από 90» σημαίνει score >= 90.

    Α9. Γράψε εσύ: repeat_text (4′)¶
