    Κάρτα: Συγκρούσεις¶

    Με μια ματιά

    • Τι προσθέτει: το παιχνίδι καταλαβαίνει πότε δύο αντικείμενα ακουμπούν. Στο πρότυπο ο παίκτης μαζεύει έναν κίτρινο στόχο που αλλάζει θέση μετά από κάθε επαφή.
    • Αλλάζει: logic.py, game.py και check_logic.py.
    • Χρόνος: περίπου 30 λεπτά.
    • Χρειάζεσαι: το πρότυπο που τρέχει και τα κουτιά σύγκρουσης του Μαθήματος 11.

    Πότε τη θέλεις¶

    Σε σχεδόν κάθε παιχνίδι: ο παίκτης μαζεύει κάτι, χτυπά έναν εχθρό, φτάνει σε ένα σημείο ή πατά ένα κουμπί. Όλα αυτά είναι η ίδια ερώτηση: ακουμπούν αυτά τα δύο;

    Πώς δουλεύει¶

    Κάθε αντικείμενο έχει ένα κουτί: ένα ορθογώνιο (x, y, πλάτος, ύψος). Δύο κουτιά επικαλύπτονται όταν επικαλύπτονται και στον άξονα x και στον άξονα y. Αν ξεχάσεις τον έναν άξονα, θα βγαίνει «σύγκρουση» ανάμεσα σε αντικείμενα που είναι πολύ μακριά το ένα από το άλλο.

    Τρία πράγματα αλλάζουν:

    1. Η boxes_overlap απαντά αν δύο κουτιά επικαλύπτονται. Αν ακουμπούν μόνο στην άκρη τους, δεν επικαλύπτονται.
    2. Η shrink_box μικραίνει ένα κουτί από όλες τις πλευρές. Το κουτί σύγκρουσης του παίκτη είναι λίγο μικρότερο από το τετράγωνο που φαίνεται, ώστε ο παίκτης να μη χάνει όταν απλώς «γλιστρά» στην άκρη (όπως στο Μάθημα 11).
    3. Η next_index δίνει τον επόμενο στόχο από μια λίστα θέσεων και, μετά το τελευταίο, ξαναρχίζει από το πρώτο.

    Μέχρι τώρα οι πόντοι του προτύπου ήταν τα δευτερόλεπτα που πέρασαν (ο προσωρινός κανόνας). Εδώ οι πόντοι έρχονται από τις συγκρούσεις, γι' αυτό η γραμμή που τους έκανε ίσους με τον χρόνο φεύγει.

    Τα μπλοκ κώδικα διαβάζονται όπως εξηγείται στην αρχική σελίδα των καρτών.

    Βήμα 1: το logic.py¶

    Ο στόχος που είναι ενεργός είναι ένας αριθμός μέσα στα δεδομένα του παιχνιδιού, ο game["target"]:

    logic.py · αντικατάσταση: new_game
    def new_game(x, y):
    """Τα δεδομένα ενός νέου παιχνιδιού: ο παίκτης στη θέση (x, y), ο χρόνος και οι πόντοι στο μηδέν και ο πρώτος στόχος ενεργός."""
    return {"x": x, "y": y, "time": 0.0, "score": 0, "target": 0}        # ← ΝΕΟ: το "target"
    logic.py · προσθήκη στο τέλος
    def boxes_overlap(a, b):
    """True αν τα κουτιά a και b, της μορφής (x, y, πλάτος, ύψος), επικαλύπτονται. Αν απλώς ακουμπούν, δεν επικαλύπτονται."""
    ax, ay, a_width, a_height = a
    bx, by, b_width, b_height = b
    return ax < bx + b_width and bx < ax + a_width and ay < by + b_height and by < ay + a_height


def shrink_box(box, amount):
    """Το κουτί box μικρότερο κατά amount pixel από κάθε πλευρά: το κέντρο του μένει ίδιο."""
    x, y, width, height = box
    return (x + amount, y + amount, width - 2 * amount, height - 2 * amount)


def next_index(index, count):
    """Ο επόμενος αριθμός θέσης σε μια λίστα με count στοιχεία: μετά το τελευταίο ξαναρχίζει από το 0."""
    return (index + 1) % count

    Βήμα 3: το game.py¶

    Οι τρεις νέες συναρτήσεις μπαίνουν στην εισαγωγή:

    game.py · εισαγωγές από το logic
    from logic import GAME_OVER, MENU, PLAYING, boxes_overlap, move, new_game, next_index, next_state, shrink_box

    Οι θέσεις του στόχου, το μέγεθός του και το περιθώριο του κουτιού σύγκρουσης:

    game.py · ρυθμίσεις
    TARGET_SIZE = 30                   # το μέγεθος του στόχου
TARGET_SPOTS = ((100, 100), (500, 120), (300, 400), (80, 380))        # οι θέσεις που παίρνει ο στόχος, με τη σειρά
HIT_MARGIN = 6                     # το κουτί σύγκρουσης του παίκτη είναι μικρότερο κατά τόσα pixel από κάθε πλευρά

    Η update_game ελέγχει τη σύγκρουση μετά την κίνηση. Πρόσεξε ότι η γραμμή game["score"] = int(game["time"]) έφυγε:

    game.py · αντικατάσταση: update_game
    def update_game(game, dt):
    """Ένα καρέ του παιχνιδιού. ΕΔΩ ΜΠΑΙΝΕΙ Ο ΚΑΝΟΝΑΣ ΣΑΣ.

    Αλλάζει τα δεδομένα του game και επιστρέφει μια ενέργεια για τον πίνακα μεταβάσεων (π.χ. «lose» όταν χάνει ο παίκτης),
    ή None αν το παιχνίδι συνεχίζεται."""
    dx, dy = read_direction()
    game["x"] = move(game["x"], dx, PLAYER_SPEED, dt, PLAY_AREA.left, PLAY_AREA.right - PLAYER_SIZE)
    game["y"] = move(game["y"], dy, PLAYER_SPEED, dt, PLAY_AREA.top, PLAY_AREA.bottom - PLAYER_SIZE)
    game["time"] += dt
    player_box = shrink_box((game["x"], game["y"], PLAYER_SIZE, PLAYER_SIZE), HIT_MARGIN)             # ← ΝΕΟ
    spot = TARGET_SPOTS[game["target"]]                                                               # ← ΝΕΟ
    if boxes_overlap(player_box, (spot[0], spot[1], TARGET_SIZE, TARGET_SIZE)):                       # ← ΝΕΟ
        game["score"] += 10                                                                           # ← ΝΕΟ
        game["target"] = next_index(game["target"], len(TARGET_SPOTS))                                # ← ΝΕΟ
    if game["time"] >= DEMO_SECONDS:        # ΣΒΗΣΤΕ ΤΟ: ο προσωρινός κανόνας
        return "lose"
    return None

    Ο στόχος ζωγραφίζεται στη θέση του:

    game.py · σχεδίαση
    def draw_target(surface, game):
    """Ζωγραφίζει τον ενεργό στόχο."""
    spot = TARGET_SPOTS[game["target"]]
    pygame.draw.rect(surface, YELLOW, (spot[0], spot[1], TARGET_SIZE, TARGET_SIZE))

    Ο βρόχος καλεί τη νέα συνάρτηση σχεδίασης:

    game.py · ο βρόχος του παιχνιδιού
    game = new_game(START_X, START_Y)
state = MENU

running = True
while running:
    dt = min(clock.tick(FPS) / 1000, MAX_DT)

    for action in handle_events(state):
        new_state = next_state(state, action)
        if action == "quit":
            running = False
        elif new_state != state:
            if action == "play":
                game = new_game(START_X, START_Y)      # νέο παιχνίδι: τα δεδομένα ξαναρχίζουν από την αρχή
            state = new_state

    if state == PLAYING:
        action = update_game(game, dt)
        if action is not None:
            state = next_state(state, action)

    screen.fill(BACKGROUND)
    if state == MENU:
        draw_menu(screen)
    else:
        draw_target(screen, game)                      # ← ΝΕΟ
        draw_player(screen, game)
        draw_hud(screen, font, game)
        if state == GAME_OVER:
            draw_game_over(screen, game)
    pygame.display.flip()

pygame.quit()

    Ο χρόνος του προτύπου

    Το πρότυπο τελειώνει μόνο του μετά από 5 δευτερόλεπτα. Για να προλάβεις να μαζέψεις τους στόχους με την ησυχία σου, αύξησε προσωρινά το DEMO_SECONDS.

    Έτοιμο όταν¶

    • Ένα κίτρινο τετράγωνο φαίνεται στην πάνω αριστερή περιοχή του παραθύρου.
    • Όταν ο παίκτης το αγγίξει, οι πόντοι αυξάνονται κατά 10 και ο στόχος εμφανίζεται σε άλλη θέση.
    • Ο παίκτης πρέπει να μπει λίγο μέσα στον στόχο για να τον μαζέψει: αν απλώς τον ακουμπήσει με την άκρη του, δεν γίνεται σύγκρουση.
    • Οι πόντοι δεν επιστρέφουν στο 0 και δεν ακολουθούν πια τον χρόνο.
    • Περνούν όλες οι δοκιμές του check_logic.py.

    Συνηθισμένα λάθη¶

    Τι βλέπεις Πιθανή αιτία
    Οι πόντοι αυξάνονται κατά 10 και αμέσως ξαναγίνονται όσα τα δευτερόλεπτα που πέρασαν Η γραμμή game["score"] = int(game["time"]) έμεινε στην update_game και ξαναγράφει τους πόντους σε κάθε καρέ
    Οι πόντοι τρέχουν όσο ο παίκτης μένει πάνω στον στόχο Λείπει η γραμμή που αλλάζει την game["target"] και ο στόχος δεν φεύγει
    Ο παίκτης «ακουμπά» τον στόχο ενώ βρίσκεται πολύ μακριά του, στην ίδια στήλη Στην boxes_overlap λείπουν οι δύο συγκρίσεις για τον άξονα y

    Δοκίμασε και κάτι δικό σου¶

    • Αύξησε το HIT_MARGIN σε 14. Πόσο πιο εύκολο ή δύσκολο γίνεται το παιχνίδι;
    • Βάλε τον στόχο να εμφανίζεται σε τυχαία θέση με τη random.randint και όχι σε θέσεις της λίστας (δες την κάρτα Πολλά αντικείμενα).
    • Κάνε τον στόχο κόκκινο: ο παίκτης χάνει πόντους όταν τον αγγίξει. Ποια γραμμή της update_game αλλάζεις;
