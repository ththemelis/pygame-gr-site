    Κάρτα: Ήχοι και μουσική¶

    Με μια ματιά

    • Τι προσθέτει: ήχους σε ό,τι συμβαίνει στο παιχνίδι (έναρξη, πόντος, χτύπημα, τέλος) και μουσική υπόβαθρο.
    • Αλλάζει: το game.py. Το logic.py και οι δοκιμές μένουν ίδια.
    • Χρόνος: περίπου 20 λεπτά.
    • Χρειάζεσαι: το make_sounds.py του Μαθήματος 12 και ό,τι έμαθες εκεί για την pygame.mixer.

    Πότε τη θέλεις¶

    Σχεδόν πάντα. Ένας ήχος στο σωστό σημείο κάνει το παιχνίδι να φαίνεται πιο ζωντανό και λέει στον παίκτη τι έγινε χωρίς να κοιτάξει την οθόνη.

    Πριν ξεκινήσεις¶

    1. Αντέγραψε το make_sounds.py από τον φάκελο του Μαθήματος 12 στον φάκελο του project σου.
    2. Τρέξε το μία φορά: python make_sounds.py. Φτιάχνει τον φάκελο assets με έξι ήχους: click, start, point, hit, game_over και music.

    Πώς δουλεύει¶

    Οι ήχοι φορτώνονται μία φορά, στην αρχή του προγράμματος, και μπαίνουν σε ένα λεξικό με το όνομά τους. Μια μικρή συνάρτηση, η play_sound, παίζει έναν ήχο με το όνομά του. Η τέχνη είναι να καλείς την play_sound τη στιγμή που γίνεται κάτι, και όχι σε κάθε καρέ: οι ενέργειες του βρόχου ("play", το τέλος του παιχνιδιού) είναι τα σωστά σημεία.

    Η μουσική δουλεύει διαφορετικά: φορτώνεται μία φορά, ξεκινά με pygame.mixer.music.play(-1) (το -1 την επαναλαμβάνει συνέχεια) και σταματά με pygame.mixer.music.stop().

    Το πρότυπο δεν έχει ακόμη πόντους ή χτυπήματα. Για να ακούσεις τον ήχο point φτιάχνεις ένα προσωρινό πλήκτρο, το SPACE. Έχει το σχόλιο ΣΒΗΣΤΕ ΤΟ, άρα ο check_project.py θα σου θυμίσει να το αφαιρέσεις. Στο δικό σου παιχνίδι θα γράψεις play_sound("point") εκεί που ο παίκτης κερδίζει έναν πόντο.

    Τα μπλοκ κώδικα διαβάζονται όπως εξηγείται στην αρχική σελίδα των καρτών.

    Βήμα 1: οι ρυθμίσεις¶

    game.py · ρυθμίσεις
    SOUND_NAMES = ("click", "start", "point", "hit", "game_over")      # τα εφέ του Μαθήματος 12
MUSIC_FILE = "assets/music.wav"                                    # η μουσική του Μαθήματος 12
VOLUME = 0.5                       # η ένταση των ήχων, από 0 έως 1

    Βήμα 2: η φόρτωση¶

    Αμέσως μετά το ρολόι φορτώνονται οι ήχοι και η μουσική και γράφεται η play_sound:

    game.py · αντικατάσταση: clock
    clock = pygame.time.Clock()

sounds = {}                                                        # ← ΝΕΟ: όλα τα παρακάτω
for name in SOUND_NAMES:
    sounds[name] = pygame.mixer.Sound(f"assets/{name}.wav")
    sounds[name].set_volume(VOLUME)
pygame.mixer.music.load(MUSIC_FILE)
pygame.mixer.music.set_volume(VOLUME)


def play_sound(name):
    """Παίζει τον ήχο name."""
    sounds[name].play()

    Βήμα 3: το προσωρινό πλήκτρο και ο βρόχος¶

    Το SPACE γίνεται η ενέργεια "beep", για δοκιμή:

    game.py · αντικατάσταση: KEY_ACTIONS
    KEY_ACTIONS = {
    (MENU, pygame.K_SPACE): "play",
    (MENU, pygame.K_ESCAPE): "quit",
    (PLAYING, pygame.K_SPACE): "beep",         # ΣΒΗΣΤΕ ΤΟ: προσωρινό πλήκτρο για δοκιμή ήχου
    (PLAYING, pygame.K_ESCAPE): "menu",
    (GAME_OVER, pygame.K_SPACE): "play",
    (GAME_OVER, pygame.K_ESCAPE): "menu",
}

    Ο βρόχος παίζει τους ήχους στα σωστά σημεία: ήχος και μουσική όταν ξεκινά το παιχνίδι, ήχος όταν τελειώνει, και η μουσική σταματά όταν τελειώσει το παιχνίδι ή όταν βγεις στο μενού:

    game.py · ο βρόχος του παιχνιδιού
    game = new_game(START_X, START_Y)
state = MENU

running = True
while running:
    dt = min(clock.tick(FPS) / 1000, MAX_DT)

    for action in handle_events(state):
        new_state = next_state(state, action)
        if action == "quit":
            running = False
        elif action == "beep":                                 # ← ΝΕΟ (ΣΒΗΣΤΕ ΤΟ αργότερα)
            play_sound("point")                                # ← ΝΕΟ
        elif new_state != state:
            if action == "play":
                game = new_game(START_X, START_Y)      # νέο παιχνίδι: τα δεδομένα ξαναρχίζουν από την αρχή
                play_sound("start")                            # ← ΝΕΟ
                pygame.mixer.music.play(-1)                    # ← ΝΕΟ
            elif action == "menu":                             # ← ΝΕΟ
                pygame.mixer.music.stop()                      # ← ΝΕΟ
            state = new_state

    if state == PLAYING:
        action = update_game(game, dt)
        if action is not None:
            state = next_state(state, action)
            play_sound("game_over")                            # ← ΝΕΟ
            pygame.mixer.music.stop()                          # ← ΝΕΟ

    screen.fill(BACKGROUND)
    if state == MENU:
        draw_menu(screen)
    else:
        draw_player(screen, game)
        draw_hud(screen, font, game)
        if state == GAME_OVER:
            draw_game_over(screen, game)
    pygame.display.flip()

pygame.quit()

    Ο χρόνος του προτύπου

    Το πρότυπο τελειώνει μόνο του μετά από 5 δευτερόλεπτα. Έτσι ακούς εύκολα και τον ήχο game_over.

    Έτοιμο όταν¶

    • Όταν ξεκινά το παιχνίδι ακούγεται ο ήχος start και αρχίζει η μουσική.
    • Κάθε πάτημα του SPACE παίζει τον ήχο point, μία φορά.
    • Όταν τελειώνει το παιχνίδι ακούγεται ο game_over και η μουσική σταματά.
    • Όταν βγαίνεις στο μενού με το ESC, η μουσική σταματά.

    Συνηθισμένα λάθη¶

    Τι βλέπεις Πιθανή αιτία
    FileNotFoundError: No file 'assets/click.wav' found in working directory Δεν έτρεξες το make_sounds.py, ή τρέχεις το παιχνίδι από άλλον φάκελο και όχι από αυτόν που έχει τον φάκελο assets
    Ο ήχος ακούγεται συνέχεια, σαν βουητό Έβαλες την play_sound μέσα στον βρόχο, σε κάθε καρέ, και όχι στο σημείο όπου γίνεται κάτι
    Η μουσική συνεχίζει όταν γυρίζεις στο μενού Λείπει το pygame.mixer.music.stop() από το σημείο όπου βγαίνεις στο μενού

    Δοκίμασε και κάτι δικό σου¶

    • Δώσε διαφορετική ένταση στα εφέ και στη μουσική (η set_volume δέχεται αριθμό από 0 έως 1).
    • Γράψε ένα πλήκτρο M που κλείνει και ανοίγει τη μουσική με τις pygame.mixer.music.pause() και pygame.mixer.music.unpause().
    • Άλλαξε νότες και διάρκειες στο make_sounds.py, τρέξ' το ξανά και άκουσε τη διαφορά. Κράτα τα ονόματα των αρχείων.
