    Κάρτα: Επίπεδα¶

    Με μια ματιά

    • Τι προσθέτει: το παιχνίδι δυσκολεύει όσο ανεβαίνουν οι πόντοι. Το επίπεδο φαίνεται στη ζώνη των ενδείξεων και η ταχύτητα μεγαλώνει σε κάθε επίπεδο, μέχρι ένα όριο.
    • Αλλάζει: logic.py, game.py και check_logic.py.
    • Χρόνος: περίπου 20 λεπτά.
    • Χρειάζεσαι: το πρότυπο που τρέχει και τους πόντους (game["score"]).

    Πότε τη θέλεις¶

    Όταν το παιχνίδι γίνεται βαρετό αν μένει πάντα ίδιο. Τα επίπεδα ανταμείβουν τον παίκτη που τα πάει καλά: τα εμπόδια πιο γρήγορα, λιγότερος χρόνος, μικρότερα ανοίγματα.

    Πώς δουλεύει¶

    Το επίπεδο δεν αποθηκεύεται πουθενά: υπολογίζεται κάθε φορά από τους πόντους. Έτσι δεν υπάρχει κάτι που να ξεχάσεις να μηδενίσεις όταν ξεκινά νέο παιχνίδι.

    • Η level_for_score δίνει το επίπεδο: 1 στην αρχή και +1 κάθε POINTS_PER_LEVEL πόντους.
    • Η speed_for_level δίνει την ταχύτητα του επιπέδου: ξεκινά από μια βασική τιμή, αυξάνεται κατά ένα βήμα σε κάθε επίπεδο και δεν ξεπερνά ένα μέγιστο.

    Στο πρότυπο ο παίκτης είναι το μόνο αντικείμενο, γι' αυτό η ταχύτητα που μεγαλώνει είναι η δική του. Στο δικό σου παιχνίδι θα βάλεις τη speed_for_level εκεί που ταιριάζει: στην ταχύτητα των εχθρών, στον ρυθμό που εμφανίζονται, στο μέγεθος των ανοιγμάτων.

    Τα μπλοκ κώδικα διαβάζονται όπως εξηγείται στην αρχική σελίδα των καρτών.

    Βήμα 1: το logic.py¶

    logic.py · προσθήκη στο τέλος
    def level_for_score(score, points_per_level):
    """Το επίπεδο για έναν αριθμό πόντων: ξεκινά από το 1 και ανεβαίνει κάθε points_per_level πόντους."""
    return score // points_per_level + 1


def speed_for_level(base, step, level, maximum):
    """Η ταχύτητα στο επίπεδο level: ξεκινά από base στο επίπεδο 1, αυξάνεται κατά step σε κάθε επίπεδο και δεν ξεπερνά το maximum."""
    return min(maximum, base + step * (level - 1))

    Βήμα 3: το game.py¶

    Η εισαγωγή παίρνει τις δύο νέες συναρτήσεις:

    game.py · εισαγωγές από το logic
    from logic import GAME_OVER, MENU, PLAYING, level_for_score, move, new_game, next_state, speed_for_level

    Οι νέες σταθερές:

    game.py · ρυθμίσεις
    POINTS_PER_LEVEL = 3               # κάθε τόσους πόντους ανεβαίνει το επίπεδο
SPEED_STEP = 30                    # πόσο αυξάνεται η ταχύτητα σε κάθε επίπεδο
MAX_SPEED = 420                    # η μέγιστη ταχύτητα

    Στο πρότυπο οι πόντοι είναι τα δευτερόλεπτα που πέρασαν και το παιχνίδι τελειώνει μετά από 5. Για να προλάβεις να δεις επίπεδα, αύξησε προσωρινά το όριο:

    game.py · αντικατάσταση: DEMO_SECONDS
    DEMO_SECONDS = 30                  # ΣΒΗΣΤΕ ΤΟ: ο προσωρινός κανόνας του προτύπου (το παιχνίδι τελειώνει μετά από 30 δευτερόλεπτα)

    Η update_game υπολογίζει την ταχύτητα του επιπέδου και τη χρησιμοποιεί στην κίνηση:

    game.py · αντικατάσταση: update_game
    def update_game(game, dt):
    """Ένα καρέ του παιχνιδιού. ΕΔΩ ΜΠΑΙΝΕΙ Ο ΚΑΝΟΝΑΣ ΣΑΣ.

    Αλλάζει τα δεδομένα του game και επιστρέφει μια ενέργεια για τον πίνακα μεταβάσεων (π.χ. «lose» όταν χάνει ο παίκτης),
    ή None αν το παιχνίδι συνεχίζεται."""
    level = level_for_score(game["score"], POINTS_PER_LEVEL)                                      # ← ΝΕΟ
    speed = speed_for_level(PLAYER_SPEED, SPEED_STEP, level, MAX_SPEED)                           # ← ΝΕΟ
    dx, dy = read_direction()
    game["x"] = move(game["x"], dx, speed, dt, PLAY_AREA.left, PLAY_AREA.right - PLAYER_SIZE)     # ← ΑΛΛΑΞΕ: speed αντί για PLAYER_SPEED
    game["y"] = move(game["y"], dy, speed, dt, PLAY_AREA.top, PLAY_AREA.bottom - PLAYER_SIZE)     # ← ΑΛΛΑΞΕ: speed αντί για PLAYER_SPEED
    game["time"] += dt
    game["score"] = int(game["time"])
    if game["time"] >= DEMO_SECONDS:        # ΣΒΗΣΤΕ ΤΟ: ο προσωρινός κανόνας
        return "lose"
    return None

    Η ζώνη των ενδείξεων δείχνει το επίπεδο:

    game.py · αντικατάσταση: draw_hud
    def draw_hud(surface, font, game):
    """Ζωγραφίζει τη ζώνη των ενδείξεων."""
    level = level_for_score(game["score"], POINTS_PER_LEVEL)                                          # ← ΝΕΟ
    pygame.draw.rect(surface, HUD_COLOR, (0, 0, WIDTH, HUD_HEIGHT))
    draw_text(surface, font, f"Πόντοι: {game['score']}", YELLOW, (20, 14))
    draw_centered_text(surface, font, f"Επίπεδο: {level}", WHITE, (WIDTH // 2, HUD_HEIGHT // 2))      # ← ΝΕΟ
    draw_text(surface, font, "Βέλη ή WASD", GREY, (WIDTH - 180, 14))

    Έτοιμο όταν¶

    • Η ζώνη των ενδείξεων δείχνει Επίπεδο: 1 στην αρχή και Επίπεδο: 2 όταν οι πόντοι φτάσουν τους 3.
    • Στο επίπεδο 2 το τετράγωνο κινείται πιο γρήγορα από ό,τι στο επίπεδο 1.
    • Περνούν όλες οι δοκιμές του check_logic.py.

    Συνηθισμένα λάθη¶

    Τι βλέπεις Πιθανή αιτία
    Το επίπεδο ξεκινά από Επίπεδο: 0 Στη level_for_score έγραψες score // points_per_level χωρίς το + 1
    Το επίπεδο ανεβαίνει, αλλά η κίνηση μένει το ίδιο γρήγορη Στη move άφησες το PLAYER_SPEED αντί για το speed
    Αποτυγχάνει η δοκιμή speed_for_level(240, 30, 20, 420) Στη speed_for_level ξέχασες το min: η ταχύτητα δεν σταματά ποτέ να μεγαλώνει

    Δοκίμασε και κάτι δικό σου¶

    • Άλλαξε το POINTS_PER_LEVEL σε 5 και το SPEED_STEP σε 50. Πόσο γρήγορα φτάνεις στο μέγιστο;
    • Κάνε το παιχνίδι πιο εύκολο όσο ανεβαίνει το επίπεδο, αντί για πιο δύσκολο. Ποια συνάρτηση αλλάζεις;
    • Δείξε ένα μήνυμα «Επίπεδο 2» για ένα δευτερόλεπτο όταν ανεβαίνεις επίπεδο. Τι χρειάζεσαι για να καταλάβεις ότι το επίπεδο μόλις άλλαξε;
