    Φύλλο εργασίας — Μάθημα 15: Project (2/2): από το πρωτότυπο στο τελικό παιχνίδι¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 15. Εδώ είναι οι δραστηριότητες και τα παραδοτέα. Δουλεύετε ως ζεύγος: ο οδηγός κρατά το πληκτρολόγιο, ο πλοηγός ελέγχει και λέει τι να γραφτεί, και αλλάζετε ρόλους κάθε 15′.

    Τα παραδοτέα είναι αρχεία μέσα στον φάκελο του project σας. Σε κάθε κύκλο αντιγράφετε το πρότυπο που σας δίνουμε, το συμπληρώνετε και το δείχνετε στον διδάσκοντα, για το σημείο ελέγχου (ΣΕ) του κύκλου:

    • extension-plan.md για το ΣΕ5 (κύκλος 1),
    • test-table.md για το ΣΕ6 (κύκλος 2),
    • README.md για το ΣΕ7 (κύκλος 3),
    • diary.md, το ημερολόγιο προόδου, με μια εγγραφή σε κάθε κύκλο.
    Κύκλος Εργασία Σημείο ελέγχου
    1 τι λείπει, ένωση δύο καρτών, σχέδιο επέκτασης, το πρώτο χαρακτηριστικό ΣΕ5: σχέδιο επέκτασης
    2 μηνύματα σφάλματος και print, το δεύτερο χαρακτηριστικό, πίνακας δοκιμών, δοκιμή από άλλο ζεύγος ΣΕ6: πίνακας δοκιμών
    3 τελικά κείμενα, README, δήλωση βοήθειας, κατάλογος παράδοσης, προετοιμασία της παρουσίασης ΣΕ7: τελικό παιχνίδι και README
    4 φεστιβάλ παιχνιδιών, κάρτες σχολίων, αναστοχασμός —

    Μετά από κάθε κύκλο ακολουθεί διάλειμμα 15′. Η ατομική υπεράσπιση γίνεται από τον κύκλο 2 και μετά: ο διδάσκων σε καλεί για περίπου 2′ (ενότητα 3.6 του μαθήματος).

    Β. Πρόβλεψη: τι τυπώνει το print (4′)¶

    Η hurt της κάρτας Ζωές, με δύο print για να βρούμε λάθη:

    def hurt(game):
    """Ο παίκτης χτυπήθηκε: χάνει μια ζωή. Επιστρέφει "lose" όταν δεν έμεινε καμία ζωή, αλλιώς None."""
    print("πριν:", game["lives"])                  # ΣΒΗΣΤΕ ΤΟ
    game["lives"] = lose_life(game["lives"])
    print("μετά:", game["lives"])                  # ΣΒΗΣΤΕ ΤΟ
    if game["lives"] == 0:
        return "lose"
    return None

    Ο παίκτης πατά SPACE στο μενού και μετά τέσσερις φορές Enter. Στην κατάσταση PLAYING το Enter είναι η ενέργεια "hit", που καλεί τη hurt (δες τον πίνακα KEY_ACTIONS της κάρτας)· στις άλλες καταστάσεις δεν κάνει τίποτα. Πρόβλεψε πρώτα, μετά έλεγξε.

    Γ. Η δήλωση βοήθειας (4′)¶

    Πριν γράψετε την ενότητα «Πηγές και βοήθεια» (ενότητα 3.3), συμπληρώστε έναν πίνακα με ό,τι δεν είναι δικό σας. Προσθέστε γραμμές, αν χρειάζεται.

    Τι χρησιμοποιήσαμε Τι ζητήσαμε ή τι πήραμε Τι κάναμε με αυτό
    κάρτα …
    Μάθημα …
    διαδίκτυο ή εργαλείο ΤΝ

    Μεταφέρετε τον πίνακα στο README, με προτάσεις. Αν δεν χρησιμοποιήσατε τίποτα εκτός από τις κάρτες, γράψτε το. Ποιο κομμάτι κώδικα δεν το γράψατε εσείς; Μπορούν και οι δύο να το εξηγήσουν; ______________________________

    • □ README.md, project-card.md, design.md
    • □ extension-plan.md, test-table.md, diary.md

    • □ οι φάκελοι v1, v2, v3, v4

    Κύκλος 4 — Φεστιβάλ παιχνιδιών (48′)¶

    Οδηγίες (3′)¶

    Διάβασε τις ενότητες 4.1–4.3 του μαθήματος. Ο διδάσκων ανακοινώνει τη σειρά των ζευγών και δίνει τα χαρτάκια για τις κάρτες σχολίων.

    Α. Τελευταία προετοιμασία (3′)¶

    Ανοίξτε το παιχνίδι σας και τα αρχεία που θα δείξετε, και τρέξτε το μία φορά, για να ξέρετε ότι δουλεύει. Αν η σειρά σας είναι μετά, ετοιμάστε το παιχνίδι να τρέξει με μία εντολή.

    Β. Το φεστιβάλ (35′)¶

    Κάθε ζεύγος έχει 3′ επίδειξη και 2′ ερωτήσεις. Όταν δεν παρουσιάζετε, παρακολουθείτε και γράφετε μία κάρτα σχολίων για κάθε παιχνίδι (ενότητα 4.2), στο χαρτάκι του διδάσκοντα. Εδώ κρατάτε σημειώσεις:

    Στο τέλος δίνετε τις κάρτες στο ζεύγος που έφτιαξε το κάθε παιχνίδι.

    Αυτοέλεγχος¶

    Αν μπορείς να απαντήσεις «ναι» σε όλα, ολοκλήρωσες το project.

    • □ Μπορώ να βάλω μια κάρτα στο δικό μου project χωρίς να σβήσω κώδικα που έχω ήδη.
    • □ Μπορώ να ενώσω δύο κάρτες που αλλάζουν τα ίδια κομμάτια.
    • □ Μπορώ να διαβάσω ένα μήνυμα σφάλματος με πολλές γραμμές File και να πω πού ξεκίνησε το λάθος.
    • □ Μπορώ να βρω ένα λάθος με σειρά βημάτων και με print.
    • □ Μπορώ να γράψω πίνακα δοκιμών με οριακές περιπτώσεις.
    • □ Μπορώ να γράψω README με δήλωση βοήθειας.
    • □ Μπορώ να εξηγήσω κάθε συνάρτηση του logic.py και να πω τι θα γίνει αν αλλάξει μία τιμή.
