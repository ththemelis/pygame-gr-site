    Η αποστολή¶

    Το κουίζ κάνει ερωτήσεις πολλαπλής επιλογής για Python, υλικό και παιχνίδια, ελέγχει τις απαντήσεις και στο τέλος εμφανίζει πόσες ήταν σωστές, το ποσοστό, ένα σχόλιο, και πόσες σωστές είχες ανά θέμα.

    Αυτό είναι το πρώτο πρόγραμμα του μαθήματος με πραγματικό μέγεθος. Αν γραφτεί ως ένα μακρύ κομμάτι κώδικα, γίνεται δύσκολο να το διαβάσεις, να το αλλάξεις και να το ελέγξεις. Σήμερα μαθαίνεις τρία εργαλεία οργάνωσης:

    1. Συναρτήσεις: κομμάτια κώδικα με όνομα, που τα γράφεις μία φορά και τα καλείς όσες φορές θέλεις.
    2. Λεξικά: δεδομένα με ετικέτες. Μια ερώτηση έχει κείμενο, επιλογές, σωστή απάντηση και θέμα, και θέλουμε να τα ονομάζουμε.
    3. Πλειάδες: ομάδες τιμών που μένουν μαζί, π.χ. για να επιστρέφει μια συνάρτηση περισσότερες από μία τιμές.

    Στο τέλος θα μπορείς¶

    • να ορίζεις και να καλείς συναρτήσεις με παραμέτρους και να επιστρέφεις τιμές με return.
    • να ξεχωρίζεις την παράμετρο από το όρισμα και την εμφάνιση (print) από την επιστροφή τιμής.
    • να εξηγείς τι είναι εμβέλεια και γιατί οι μεταβλητές μιας συνάρτησης είναι τοπικές.
    • να χρησιμοποιείς προεπιλεγμένες τιμές παραμέτρων και ορίσματα με όνομα.
    • να χρησιμοποιείς τις ενσωματωμένες συναρτήσεις και να μη δίνεις τα ονόματά τους σε μεταβλητές.
    • να δημιουργείς λεξικά, να διαβάζεις και να αλλάζεις τιμές με κλειδιά, να τα διατρέχεις και να χρησιμοποιείς τις .pop και .update.
    • να οργανώνεις δεδομένα ως λίστα από λεξικά.
    • να δημιουργείς πλειάδες, να τις αποσυσκευάζεις και να επιστρέφεις πολλές τιμές από μια συνάρτηση.
    • να διαλέγεις ανάμεσα σε λίστα, πλειάδα, σύνολο και λεξικό και να μετατρέπεις τη μία δομή στην άλλη.
    • να ελέγχεις μια συνάρτηση με δοκιμές και να χρησιμοποιείς δικό σου module με import.
    • να προκαλείς εξαίρεση με raise και να εξηγείς τι εκτελείται όταν ένα αρχείο εισάγεται (if __name__ == "__main__":).

    Κύκλος 1 — Συναρτήσεις¶

    1.1 Γιατί χρειάζονται συναρτήσεις¶

    Στο Μάθημα 2 έγραψες τον έλεγχο εισόδου («ρώτα μέχρι να είναι έγκυρο») δύο φορές: μία για τους πόντους νίκης και μία για την επιλογή του παίκτη. Αν βρεις ένα λάθος σε αυτόν τον κώδικα, πρέπει να το διορθώσεις και στα δύο σημεία. Και αν χρειαστείς τον ίδιο έλεγχο σε δέκα σημεία, θα τον έχεις αντιγράψει δέκα φορές.

    Μια συνάρτηση (function) λύνει αυτό το πρόβλημα. Είναι ένα κομμάτι κώδικα που:

    • έχει όνομα,
    • γράφεται μία φορά,
    • και καλείται όσες φορές χρειάζεται, με διαφορετικά δεδομένα κάθε φορά.

    Συναρτήσεις έχεις ήδη χρησιμοποιήσει πολλές: print, input, len, int, random.choice. Κάποιος τις έγραψε μία φορά και εσύ τις καλείς. Τώρα μαθαίνεις να γράφεις δικές σου. Οι συναρτήσεις έχουν και ένα δεύτερο όφελος: δίνουν όνομα σε μια ενέργεια. Το ask_number(...) διαβάζεται αμέσως· οι δέκα γραμμές του βρόχου όχι.

    1.2 Ορισμός και κλήση¶

    def greet():
    print("Γεια σου")

greet()
greet()

    Γεια σου
Γεια σου
    • Η λέξη-κλειδί def (define) ξεκινά τον ορισμό. Ακολουθούν το όνομα, παρενθέσεις, και άνω-κάτω τελεία. Το σώμα γράφεται με εσοχή, όπως στο if και στο while.
    • Ο ορισμός δεν εκτελεί τον κώδικα. Απλώς δημιουργεί τη συνάρτηση και της δίνει όνομα.
    • Η κλήση (call) γράφεται με το όνομα και παρενθέσεις: greet(). Μόνο τότε εκτελείται το σώμα.
    • Χωρίς παρενθέσεις, το greet είναι απλώς το όνομα της συνάρτησης και δεν εκτελείται τίποτα.

    Μια συνάρτηση πρέπει να έχει οριστεί πριν εκτελεστεί η κλήση της. Αν καλέσεις τη greet() πριν από τον ορισμό της, παίρνεις NameError: name 'greet' is not defined. Για αυτό σε κάθε πρόγραμμα του μαθήματος οι συναρτήσεις γράφονται πρώτες και το κύριο μέρος ακολουθεί.

    1.3 Παράμετροι και ορίσματα¶

    Η greet() λέει πάντα το ίδιο. Για να δουλεύει με διαφορετικά δεδομένα, της δίνουμε παραμέτρους:

    def greet(name):
    print("Γεια σου", name)

greet("Νίκη")
greet("Αλέξης")

    Γεια σου Νίκη
Γεια σου Αλέξης

    Δύο όροι που μοιάζουν αλλά διαφέρουν:

    Όρος Πού βρίσκεται Παράδειγμα
    παράμετρος στον ορισμό: το όνομα που θα δείχνει στην τιμή το name στο def greet(name):
    όρισμα στην κλήση: η πραγματική τιμή που δίνεις το "Νίκη" στο greet("Νίκη")

    Σε κάθε κλήση, η παράμετρος παίρνει την τιμή του αντίστοιχου ορίσματος. Με περισσότερες από μία παραμέτρους, τα ορίσματα αντιστοιχίζονται με τη σειρά:

    def add(a, b):
    return a + b

print(add(2, 3))     # το a είναι 2, το b είναι 3

    Αν δώσεις λάθος πλήθος ορισμάτων, η Python το λέει καθαρά:

    TypeError: add() missing 1 required positional argument: 'b'
TypeError: add() takes 2 positional arguments but 3 were given

    1.4 Επιστροφή τιμής: return¶

    Μέχρι τώρα οι συναρτήσεις «έκαναν κάτι» (εμφάνιζαν κείμενο). Συχνά θέλουμε να υπολογίσουν κάτι και να μας το δώσουν πίσω. Αυτό κάνει το return:

    def percentage(correct, total):
    return correct * 100 / total

p = percentage(6, 8)
print(p)               # 75.0

    Η κλήση percentage(6, 8) αντικαθίσταται από την τιμή που επιστρέφεται. Γι' αυτό μπορείς να γράψεις p = percentage(6, 8), ή να τη βάλεις μέσα σε άλλη έκφραση: print(percentage(6, 8)).

    Τρεις κανόνες για το return:

    1. Το return τελειώνει αμέσως τη συνάρτηση. Ό,τι ακολουθεί δεν εκτελείται. Μπορείς να το βάλεις μέσα σε βρόχο: στην ask_number, το return number βγάζει τη συνάρτηση από τον while True μόλις βρεθεί έγκυρη τιμή.
    2. Μια συνάρτηση μπορεί να έχει πολλά return σε διαφορετικούς κλάδους. Η verdict επιστρέφει διαφορετικό κείμενο ανάλογα με το ποσοστό. Εκτελείται μόνο το πρώτο που θα συναντηθεί.
    3. Χωρίς return, η συνάρτηση επιστρέφει None, την «τιμή που δεν σημαίνει τίποτα».

    Συνηθισμένο λάθος: print αντί για return

    Η print εμφανίζει μια τιμή στην οθόνη, για τον άνθρωπο. Το return δίνει την τιμή στο πρόγραμμα, για να τη χρησιμοποιήσει παρακάτω. Δεν είναι το ίδιο:

    def percentage_wrong(correct, total):
    print(correct * 100 / total)      # εμφανίζει, αλλά δεν επιστρέφει

p = percentage_wrong(6, 8)            # εμφανίζει 75.0
print(p)                              # None

    Αν σε μια άσκηση κάποια μεταβλητή «γίνεται None», ψάξε μια συνάρτηση που εμφανίζει αντί να επιστρέφει.

    1.5 Τοπικές μεταβλητές και εμβέλεια¶

    Οι μεταβλητές που δημιουργείς μέσα σε μια συνάρτηση (και οι παράμετροί της) υπάρχουν μόνο όσο εκτελείται η κλήση, και μόνο εκεί. Λέγονται τοπικές (local). Ο χώρος όπου ένα όνομα είναι ορατό λέγεται εμβέλεια (scope).

    def total_price(price, count):
    total = price * count
    return total

print(total_price(3, 4))      # 12
print(total)                  # NameError: name 'total' is not defined

    Η total υπάρχει μόνο μέσα στην total_price. Έξω από αυτήν δεν υπάρχει.

    • Κάθε κλήση έχει δικές της τοπικές μεταβλητές. Δύο κλήσεις της ίδιας συνάρτησης δεν επηρεάζουν η μία την άλλη.
    • Ένα όνομα μέσα στη συνάρτηση και ένα όνομα με την ίδια ονομασία έξω από αυτήν είναι δύο διαφορετικές μεταβλητές. Στο Στάδιο 1 το πρόγραμμα έχει μια μεταβλητή percent και η verdict έχει παράμετρο percent: δεν σχετίζονται, παρά το ίδιο όνομα.
    • Μια συνάρτηση μπορεί να διαβάσει μεταβλητή που βρίσκεται έξω από αυτήν (π.χ. μια σταθερά). Τι γίνεται αν προσπαθήσει να την αλλάξει θα το δούμε στον κύκλο 4.

    1.6 Πώς εκτελείται μια κλήση¶

    Δες τη γραμμή print(verdict(percentage(6, 8))). Η Python υπολογίζει πάντα πρώτα την πιο εσωτερική κλήση:

    Βήμα Τι γίνεται
    1 Για να εκτελέσει την print, χρειάζεται το όρισμά της: verdict(percentage(6, 8)).
    2 Για να καλέσει τη verdict, χρειάζεται το όρισμά της: percentage(6, 8).
    3 Κλήση percentage: correct = 6, total = 8. Επιστρέφει 75.0.
    4 Κλήση verdict: percent = 75.0. Ο έλεγχος 75.0 >= 90 είναι ψευδής, ο 75.0 >= 70 αληθής. Επιστρέφει "Πολύ καλά.".
    5 Η print εμφανίζει Πολύ καλά.

    1.7 Πώς γράφονται καλές συναρτήσεις¶

    • Ένα όνομα που περιγράφει τι κάνει: percentage, ask_number. Συνήθως ρήμα ή ουσιαστικό που λέει το αποτέλεσμα.
    • Μία δουλειά ανά συνάρτηση. Η percentage μόνο υπολογίζει. Η ask_number μόνο ρωτά. Δεν ανακατεύουμε υπολογισμούς με εισόδους/εξόδους όταν δεν χρειάζεται: έτσι μπορείς να ελέγξεις τη percentage χωρίς να πληκτρολογήσεις τίποτα.
    • Μια γραμμή περιγραφής με τριπλά εισαγωγικά αμέσως μετά το def (docstring): """Επιστρέφει το ποσοστό των σωστών απαντήσεων.""". Την εμφανίζει η help(percentage) και τη διαβάζουν όσοι χρησιμοποιούν τον κώδικά σου, δηλαδή κι εσύ μετά από μια εβδομάδα.
    • Τα δεδομένα μπαίνουν από τις παραμέτρους και βγαίνουν με return, αντί να διαβάζονται από μεταβλητές έξω.

    1.8 Μορφοποίηση αριθμών σε f-string¶

    Το 75.0 σε ένα μήνυμα είναι εντάξει, αλλά το 62.5 ή το 66.66666666666667 όχι. Μέσα στα άγκιστρα ενός f-string μπορείς να ορίσεις μορφή, με άνω-κάτω τελεία:

    percent = 62.5
print(f"{percent:.1f}%")      # 62.5%
print(f"{66.6666:.1f}%")     # 66.7%
print(f"{percent:.0f}%")     # 62%

    Το .1f σημαίνει «δεκαδικός αριθμός με ένα δεκαδικό ψηφίο». Το .0f δεν κρατά κανένα, και το .2f δύο. Θα δεις να χρησιμοποιείται το .1f στα αποτελέσματα του κουίζ.

    Γιατί όχι round

    Η round(62.5) δίνει 62, και η round(87.5) δίνει 88. Η Python στρογγυλοποιεί τα «μισά» προς τον κοντινότερο άρτιο ακέραιο. Για εμφάνιση, η μορφοποίηση είναι πιο προβλέψιμη.

    1.9 Οι ενσωματωμένες συναρτήσεις¶

    Η Python έχει έτοιμες συναρτήσεις που υπάρχουν πάντα, χωρίς import: τις ενσωματωμένες (built-in). Τις περισσότερες τις έχεις ήδη χρησιμοποιήσει. Εδώ είναι μαζεμένες:

    Συνάρτηση Τι κάνει Παράδειγμα
    print(...), input(...) εμφανίζει, διαβάζει κείμενο input("Όνομα: ")
    int, float, str, bool μετατρέπει μια τιμή σε άλλον τύπο int("42") → 42
    len(x) πλήθος στοιχείων ή χαρακτήρων len("ΑΛΦΑ") → 4
    min(...), max(...) μικρότερη, μεγαλύτερη τιμή max(3, 9, 5) → 9
    sum(λίστα) άθροισμα sum([4, 8, 1]) → 13
    abs(n) απόλυτη τιμή abs(-5) → 5
    round(n) στρογγυλοποίηση (δες την ενότητα 1.8) round(7.4) → 7
    sorted(x) νέα ταξινομημένη λίστα sorted([3, 1, 2]) → [1, 2, 3]
    range(...) ακολουθία αριθμών για τον for list(range(3)) → [0, 1, 2]
    list, tuple, set, dict φτιάχνουν δομές (δες την ενότητα 3.7) set([1, 1, 2]) → {1, 2}
    help(f) εμφανίζει την περιγραφή (docstring) μιας συνάρτησης help(percentage)

    Τα ονόματα των ενσωματωμένων δεν είναι δεσμευμένα. Η Python σού επιτρέπει να δώσεις σε μια μεταβλητή το όνομα μιας ενσωματωμένης συνάρτησης. Τότε η μεταβλητή «σκεπάζει» τη συνάρτηση, και το λάθος φαίνεται μόνο στην επόμενη κλήση:

    3.1 Η πλειάδα¶

    Η πλειάδα (tuple) είναι μια ακολουθία τιμών, όπως η λίστα, αλλά δεν τροποποιείται.

    point = (3, 4)
print(point[0])          # 3
print(len(point))        # 2
print(4 in point)        # True
x, y = point             # αποσυσκευασία, βλ. 3.2
    • Γράφεται με παρενθέσεις και κόμματα. Οι παρενθέσεις είναι προαιρετικές: το point = 3, 4 είναι πλειάδα.
    • Έχει δείκτες, len, in, και διατρέχεται με for, όπως η λίστα.
    • Δεν αλλάζει: point[0] = 9 δίνει TypeError: 'tuple' object does not support item assignment.
    • Παγίδα: μια πλειάδα με ένα στοιχείο γράφεται με κόμμα, (5,). Το (5) είναι απλώς ο αριθμός 5 σε παρενθέσεις.
    • Η κενή πλειάδα είναι ().

    Πότε τη χρησιμοποιούμε: όταν μια σταθερή ομάδα τιμών ανήκει μαζί και δεν πρέπει να αλλάξει, π.χ. συντεταγμένες (x, y) ή ένα χρώμα (255, 0, 0). Θα τα συναντήσεις στο pygame.

    3.2 Αποσυσκευασία¶

    Μπορείς να μοιράσεις τα στοιχεία μιας πλειάδας σε μεταβλητές με μία εντολή:

    point = (3, 4)
x, y = point
print(x, y)          # 3 4

    Το πλήθος των μεταβλητών πρέπει να ταιριάζει με το πλήθος των στοιχείων, αλλιώς:

    ValueError: too many values to unpack (expected 2)
ValueError: not enough values to unpack (expected 3, got 2)

    Αυτό το έχεις ήδη δει. Στο Μάθημα 2 έγραψες player_score, computer_score = 0, 0 και a, b = b, a. Εκεί η δεξιά πλευρά ήταν πλειάδα, και η αριστερή την αποσυσκεύαζε. Τώρα ξέρεις τι ακριβώς έκανες.

    3.3 Πολλές τιμές επιστροφής¶

    Όταν γράφεις return a, b, η συνάρτηση επιστρέφει μία πλειάδα. Ο καλών την αποσυσκευάζει:

    def min_max(numbers):
    smallest = numbers[0]
    largest = numbers[0]
    for number in numbers:
        if number < smallest:
            smallest = number
        if number > largest:

    return smallest, largest

    4.2 Καθολικές και τοπικές μεταβλητές¶

    Μια μεταβλητή που ορίζεται έξω από κάθε συνάρτηση λέγεται καθολική (global). Μια συνάρτηση μπορεί να τη διαβάσει:

    counter = 0

def bad_increment():
    counter += 1                     # λάθος

    UnboundLocalError: cannot access local variable 'counter' where it is not associated with a value

def ask_number(prompt, low, high):
    """Ζητά ακέραιο από low έως high και ρωτά ξανά μέχρι να είναι έγκυρος."""
    while True:
        answer = input(prompt)
        try:
            number = int(answer)
        except ValueError:
            print("Γράψε έναν ακέραιο αριθμό.")
            continue
        if low <= number <= high:
            return number
        print(f"Ο αριθμός πρέπει να είναι από {low} έως {high}.")


def ask_question(number, question):
    """Εμφανίζει μια ερώτηση και επιστρέφει True αν η απάντηση του παίκτη είναι σωστή."""
    print()
    print(f"Ερώτηση {number}: {question['text']}")
    for i in range(len(question["choices"])):
        print(f"  {i + 1}) {question['choices'][i]}")
    choice = ask_number("Η απάντησή σου: ", 1, len(question["choices"]))
    return choice - 1 == question["answer"]


def percentage(correct, total):
    """Επιστρέφει το ποσοστό των σωστών απαντήσεων."""

def verdict(percent):

def play(questions):

    return correct, asked, right

    Για να θυμάσαι¶

    • Η def ορίζει μια συνάρτηση. Η κλήση με παρενθέσεις την εκτελεί. Οι παράμετροι είναι τα ονόματα στον ορισμό, τα ορίσματα οι τιμές στην κλήση.
    • Το return επιστρέφει τιμή και τελειώνει τη συνάρτηση. Χωρίς return επιστρέφεται None. Η print εμφανίζει, το return δίνει.
    • Οι μεταβλητές μέσα σε συνάρτηση είναι τοπικές. Τα δεδομένα μπαίνουν με παραμέτρους και βγαίνουν με return.
    • Το λεξικό κρατά ζεύγη κλειδιού και τιμής. Το d[k] δίνει KeyError αν λείπει το κλειδί· το d.get(k, προεπιλογή) όχι. Το in ελέγχει κλειδιά.
    • Η πλειάδα είναι ακολουθία που δεν αλλάζει. Το return a, b επιστρέφει πλειάδα και το x, y = ... την αποσυσκευάζει. Το d.items() δίνει ζεύγη (κλειδί, τιμή).
    • Λίστα: σειρά που αλλάζει. Πλειάδα: σταθερή ομάδα. Σύνολο: μοναδικά στοιχεία. Λεξικό: ετικέτες.
    • Μια συνάρτηση δεν αλλάζει τα δεδομένα που παίρνει, εκτός αν αυτή είναι η δουλειά της.
    • Δοκίμαζε τις συναρτήσεις με παραδείγματα (assert). Ένα αρχείο .py είναι module που μπορείς να κάνεις import. Το import εκτελεί όλο το αρχείο· ό,τι είναι κάτω από if __name__ == "__main__": τρέχει μόνο όταν το αρχείο τρέχει απευθείας.
    • Οι ενσωματωμένες συναρτήσεις (len, min, max, sum, abs, round, sorted…) υπάρχουν πάντα. Μην δίνεις τα ονόματά τους σε μεταβλητές. Η max(low, min(value, high)) κρατά μια τιμή μέσα σε όρια.
    • Το d.pop(κλειδί) αφαιρεί και επιστρέφει την τιμή, το d.update(άλλο) περνά ζεύγη από άλλο λεξικό.
    • Οι list, tuple, set, dict μετατρέπουν μια δομή σε άλλη. Η sorted(set(λίστα)) αφαιρεί τα διπλότυπα.
    • Η raise προκαλεί εξαίρεση. Η raise NotImplementedError σημαίνει «δεν έχει γραφτεί ακόμη».
