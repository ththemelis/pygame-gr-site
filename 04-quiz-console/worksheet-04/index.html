    Φύλλο εργασίας — Μάθημα 4: Κουίζ γνώσεων¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 4. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε τον κώδικα στο sandbox.py.

    Οι ασκήσεις «Γράψε εσύ» γράφονται στο αρχείο exercises.py. Μετά από κάθε μία, τρέξε:

    python check_exercises.py

    Το πρόγραμμα ελέγχει τη συνάρτησή σου και σου δείχνει [ΟΚ] ή [ΛΑΘΟΣ] με το αναμενόμενο και το δικό σου αποτέλεσμα. Οι συναρτήσεις που δεν έχεις γράψει ακόμη εμφανίζονται ως «δεν είναι έτοιμη ακόμη».

    Κάθε συνάρτηση που δεν έχεις γράψει ακόμη περιέχει τη γραμμή raise NotImplementedError («δεν έχει γραφτεί ακόμη»). Την αντικαθιστάς με τον κώδικά σου. Την εντολή raise θα τη μάθεις στον κύκλο 4.

    Κύκλος Εργασία Αποτέλεσμα
    1 Συναρτήσεις, return, εμβέλεια, ενσωματωμένες συναρτήσεις Τρεις συναρτήσεις του κουίζ + count_vowels
    2 Λεξικά, λίστα από λεξικά, .pop, .update Κουίζ που κάνει τις ερωτήσεις + letter_counts
    3 Πλειάδες, πολλές τιμές επιστροφής, .items(), μετατροπές δομών Αποτελέσματα ανά θέμα + min_max
    4 Προεπιλογές, εμβέλεια, δοκιμές, main, raise, import Ολοκληρωμένο κουίζ + ask_yes_no

    Μετά από κάθε κύκλο ακολουθεί διάλειμμα 15′.

    • □ Μπορώ να διαβάσω εκφράσεις όπως QUESTIONS[0]["choices"][1] από αριστερά προς τα δεξιά.
    • □ Ξέρω πότε το d[k] δίνει σφάλμα και πότε δίνει τιμή το d.get(k, προεπιλογή).
    • □ Ξέρω τι σημαίνει x, y = κάτι και πώς επιστρέφονται πολλές τιμές.
    • □ Μπορώ να διαλέξω ανάμεσα σε λίστα, πλειάδα, σύνολο και λεξικό για ένα συγκεκριμένο πρόβλημα.
    • □ Ξέρω ποιες συναρτήσεις είναι ενσωματωμένες και γιατί δεν δίνω τα ονόματά τους σε μεταβλητές.
    • □ Μπορώ να μετατρέψω μια λίστα σε σύνολο και πίσω, και να αφαιρέσω διπλότυπα.
    • □ Ξέρω τι εκτελείται όταν κάνω import και τι κάνει το if __name__ == "__main__":.
