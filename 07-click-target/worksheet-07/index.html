    Ε. Γράψε εσύ: inside_rect (8′)¶

    Στο exercises.py, γράψε το σώμα της inside_rect(x, y, left, top, width, height). Επιστρέφει True αν το σημείο (x, y) είναι μέσα στο ορθογώνιο που ξεκινά από το (left, top) και έχει το δοσμένο πλάτος και ύψος. Είναι η ίδια δουλειά που κάνει η collidepoint.

    Η αριστερή και η πάνω πλευρά ανήκουν στο ορθογώνιο. Η δεξιά και η κάτω δεν ανήκουν.

    Παραδείγματα: inside_rect(5, 5, 0, 0, 10, 10) επιστρέφει True, και inside_rect(10, 5, 0, 0, 10, 10) επιστρέφει False.

    Υποδείξεις: χρειάζεσαι δύο συγκρίσεις ενωμένες με and. Η αλυσιδωτή σύγκριση του Μαθήματος 2 (1 <= n <= 5) κάνει τη συνθήκη πιο σύντομη, αλλά θυμήσου ότι η μία πλευρά δεν περιλαμβάνεται. Στο τέλος, return. Τρέξε python check_exercises.py.

    Ε. Γράψε εσύ: accuracy και ακρίβεια στο παιχνίδι (9′)¶

    Μέρος 1 (5′). Στο exercises.py, γράψε το σώμα της accuracy(hits, misses). Επιστρέφει την ακρίβεια ως ποσοστό: πόσα από όλα τα κλικ (hits + misses) ήταν επιτυχίες, από 0 έως 100. Αν δεν έγινε κανένα κλικ, επιστρέφει 0.

    Παραδείγματα: accuracy(5, 0) επιστρέφει 100.0, accuracy(5, 5) επιστρέφει 50.0, και accuracy(0, 0) επιστρέφει 0.

    Υποδείξεις: όλα τα κλικ είναι το hits + misses. Αν είναι 0, η διαίρεση θα δώσει σφάλμα· έλεγξέ το πρώτα, όπως είδες στα προηγούμενα μαθήματα. Τρέξε python check_exercises.py μέχρι να δεις ΟΛΑ ΟΚ.

    Μέρος 2 (4′). Στο 04-final.py, στην οθόνη νίκης, πρόσθεσε μια γραμμή Ακρίβεια: 83% (για 5 επιτυχίες και 1 αστοχία), κάτω από το «Κέρδισες.». Φέρε τη συνάρτηση με from exercises import accuracy (στην αρχή του αρχείου) και χρησιμοποίησε f"Ακρίβεια: {accuracy(GOAL, misses):.0f}%" και την draw_centered_text. Μετακίνησε τα άλλα δύο κείμενα λίγο πιο πάνω και πιο κάτω ώστε να μη συμπέσουν.
