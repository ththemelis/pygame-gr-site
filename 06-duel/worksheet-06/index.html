    Α. Πρόβλεψη (4′)¶

    class Fighter:
    def __init__(self, name, health):
        self.name = name
        self.health = health
        self.max_health = health

    def take_damage(self, amount):
        self.health -= amount
        if self.health < 0:
            self.health = 0

    def restore(self, amount):
        gained = amount
        if self.health + gained > self.max_health:
            gained = self.max_health - self.health
        self.health += gained
        return gained

f = Fighter("Α", 30)
f.take_damage(12)
print(f.health)
print(f.restore(5))
print(f.restore(50))
print(f.health)

    Ε. Γράψε εσύ: η κλάση Stamina (9′)¶

    Στο exercises.py, γράψε την κλάση Stamina, την αντοχή ενός μαχητή (από 0 έως ένα μέγιστο):

    • Stamina(maximum): ιδιότητες maximum και value. Στην αρχή το value είναι ίσο με το maximum.
    • spend(amount): αν το value είναι τουλάχιστον amount, το μειώνει κατά amount και επιστρέφει True. Αλλιώς δεν αλλάζει τίποτα και επιστρέφει False.
    • rest(amount): αυξάνει το value κατά amount, χωρίς να ξεπεράσει το maximum. Δεν επιστρέφει τίποτα.
    • is_empty(): επιστρέφει True αν το value είναι 0.

    Παράδειγμα: για Stamina(10), η spend(4) επιστρέφει True (το value γίνεται 6), η spend(7) επιστρέφει False (το value μένει 6) και η spend(6) επιστρέφει True (το value γίνεται 0, οπότε η is_empty() είναι True).

    Υποδείξεις: η rest μοιάζει με την restore (αλλά δεν επιστρέφει τίποτα). Στην spend το return False μπαίνει πρώτο, όταν δεν αρκεί η αντοχή. Τρέξε python check_exercises.py.

    Αυτοέλεγχος¶

    • □ Μπορώ να εξηγήσω τη διαφορά κλάσης και αντικειμένου.

    • □ Ξέρω τι είναι το self και γιατί οι ιδιότητες γράφονται με self. μέσα σε μέθοδο.
    • □ Μπορώ να γράψω μέθοδο που αλλάζει ιδιότητες και μέθοδο που επιστρέφει τιμή.
    • □ Ξέρω γιατί η attack(self, other) αλλάζει το other, και ότι b = a δεν φτιάχνει αντίγραφο.
    • □ Μπορώ να διατρέξω μια λίστα αντικειμένων και να διαβάσω ή να αλλάξω τις ιδιότητές τους.
    • □ Μπορώ να αποφασίσω αν κάτι είναι μέθοδος ή συνάρτηση.
