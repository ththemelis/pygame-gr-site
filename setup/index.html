    Εγκατάσταση και ρύθμιση¶

    Σε αυτή τη σελίδα ετοιμάζεις τον υπολογιστή σου για όλα τα μαθήματα: Python, VS Code και, από το Μάθημα 7, το pygame-ce. Στους υπολογιστές του εργαστηρίου συνήθως είναι ήδη εγκατεστημένα· τότε πήγαινε κατευθείαν στη λίστα ελέγχου στο τέλος της σελίδας. Οι οδηγίες γράφτηκαν για Windows.

    1. Python¶

    Έλεγξε πρώτα αν υπάρχει. Άνοιξε τερματικό (στα Windows: Έναρξη, γράψε terminal ή PowerShell) και γράψε:

    python --version

    Αν απαντήσει Python 3. και έναν αριθμό, π.χ. Python 3.13.5, η Python υπάρχει. Το υλικό δοκιμάστηκε με την Python 3.13: χρησιμοποίησε αυτήν ή μια νεότερη. Αν η εντολή δεν αναγνωρίζεται, ή ανοίγει το Microsoft Store, ακολούθησε τα παρακάτω βήματα.

    Εγκατάσταση

    1. Άνοιξε τη σελίδα https://www.python.org/downloads/windows/ και διάλεξε την έκδοση Python 3.13 (την τελευταία της σειράς 3.13).
    2. Κατέβασε το Windows installer (64-bit) και τρέξε το.
    3. Στην πρώτη οθόνη του προγράμματος εγκατάστασης τσέκαρε το κουτάκι Add python.exe to PATH, που βρίσκεται στο κάτω μέρος. Αν το ξεχάσεις, η εντολή python δεν θα αναγνωρίζεται.
    4. Πάτα Install Now, περίμενε να τελειώσει και πάτα Close.
    5. Άνοιξε νέο τερματικό και γράψε ξανά python --version.

    Νέο τερματικό μετά την εγκατάσταση

    Η ρύθμιση PATH διαβάζεται μόνο από τερματικά που ανοίγουν μετά την εγκατάσταση. Αν η εντολή δεν αναγνωρίζεται αμέσως, κλείσε όλα τα παράθυρα του τερματικού (και το VS Code) και άνοιξέ τα ξανά.

    Ο νέος τρόπος της python.org

    Από την Python 3.14 η python.org προτείνει ως κύριο τρόπο εγκατάστασης στα Windows το εργαλείο Python install manager, αντί για το κλασικό πρόγραμμα εγκατάστασης. Αν το προτιμήσεις, εγκατάστησέ το από τη σελίδα https://www.python.org/downloads/ (ή από το Microsoft Store) και μετά γράψε στο τερματικό py install 3.13. Αν σε ρωτήσει αν θέλεις να προστεθεί ένας φάκελος στο PATH, αποδέξου. Και με τους δύο τρόπους, η εντολή py --version δείχνει ποια Python έχεις.

    Αν δεν δουλεύει η εντολή python

    Τι βλέπεις Τι κάνεις
    Το τερματικό λέει ότι η python δεν αναγνωρίζεται Δοκίμασε py --version. Αν δουλεύει, γράφε py αντί για python σε όλα τα μαθήματα. Αλλιώς κατάργησε την Python (Ρυθμίσεις, Εφαρμογές) και ξανακάνε την εγκατάσταση με το κουτάκι Add python.exe to PATH τσεκαρισμένο
    Ανοίγει το Microsoft Store Τα Windows έχουν συντομεύσεις που στέλνουν τις εντολές python και python3 στο Store. Στις Ρυθμίσεις γράψε στην αναζήτηση app execution aliases και απενεργοποίησε τα python.exe και python3.exe
    Η pip δεν αναγνωρίζεται Γράψε python -m pip αντί για pip, όπως στις οδηγίες παρακάτω

    2. VS Code¶

    1. Κατέβασε το VS Code από το https://code.visualstudio.com/ και εγκατέστησέ το. Οι προεπιλογές αρκούν.
    2. Άνοιξε το VS Code. Στο αριστερό μενού πάτα Extensions (ή Ctrl + Shift + X), γράψε Python και εγκατέστησε την επέκταση Python με εκδότη Microsoft. Μπορεί να εγκατασταθούν μαζί και άλλες επεκτάσεις της Microsoft· είναι φυσιολογικό.
    3. Άνοιξε τον φάκελο του μαθήματος: File → Open Folder.
    4. Άνοιξε τερματικό: Terminal → New Terminal. Η γραμμή του τερματικού πρέπει να δείχνει τον φάκελο του μαθήματος.
    5. Άνοιξε ένα αρχείο .py. Κάτω δεξιά πρέπει να φαίνεται η έκδοση της Python, π.χ. 3.13.5. Αν δεν φαίνεται, πάτα Ctrl + Shift + P, γράψε Python: Select Interpreter και διάλεξε την Python 3.13.

    Στα μαθήματα τρέχουμε τα προγράμματα από το τερματικό, με python όνομα-αρχείου.py. Το κουμπί ▷ (Run Python File) πάνω δεξιά στον επεξεργαστή κάνει το ίδιο.

    3. Πρώτη δοκιμή¶

    1. Φτιάξε έναν φάκελο python-games και μέσα του τον φάκελο hello. Άνοιξε τον hello στο VS Code.

    2. Φτιάξε ένα αρχείο hello.py με αυτό το περιεχόμενο:

      name = input("Πώς σε λένε; ")
print("Γεια σου,", name)

    3. Στο τερματικό του VS Code γράψε:

      python hello.py

    Το πρόγραμμα σε ρωτά το όνομά σου και σε χαιρετά:

    Πώς σε λένε; Νίκη
Γεια σου, Νίκη

    Αν το είδες αυτό, έχεις ό,τι χρειάζεσαι για τα Μαθήματα 1 έως 6.

    4. pygame-ce (από το Μάθημα 7)¶

    Το pygame-ce δεν χρειάζεται μέχρι το Μάθημα 7. Όταν φτάσεις εκεί, γράψε στο τερματικό:

    python -m pip install pygame-ce

    Έλεγξε ότι εγκαταστάθηκε:

    python -c "import pygame; print(pygame.version.ver)"

    Θα δεις μια γραμμή που αρχίζει με pygame-ce και περιέχει τις εκδόσεις των SDL και Python, και μετά τον αριθμό έκδοσης του pygame-ce.

    Εγκατάστησε μόνο το ένα από τα δύο

    Τα πακέτα pygame και pygame-ce παρέχουν module με το ίδιο όνομα και δεν πρέπει να είναι μαζί στο ίδιο περιβάλλον Python. Αν έχεις εγκαταστήσει κατά λάθος το pygame, σβήσε και τα δύο και εγκατέστησε μόνο το pygame-ce. Όταν ρωτήσει «Proceed (Y/n)?», γράψε y:

    python -m pip uninstall pygame pygame-ce
python -m pip install pygame-ce

    Λίστα ελέγχου¶

    • □ Η python --version δείχνει Python 3.13 ή νεότερη.
    • □ Το VS Code ανοίγει φάκελο, ανοίγει τερματικό και βλέπει την Python.
    • □ Το hello.py τρέχει και σε χαιρετά με το όνομά σου.
    • □ (Για το Μάθημα 7) Η εντολή python -c "import pygame" δεν δίνει σφάλμα.

    macOS και Linux

    Οι οδηγίες γράφτηκαν για Windows. Σε macOS και Linux η εντολή είναι συνήθως python3 και όχι python. Αν δουλεύεις εκεί και κάτι δεν ταιριάζει, ρώτα τον διδάσκοντα.
